(unnamed in the exports; the tree names it CMessage112 by subtype, like
CMessage95/CMessage120). Its slots: 0x4B2340 (the shared empty deleting

Layout, from the constructor and the pair: CResRef m_cResSound at +0x0C,
BYTE m_nChannel at +0x14, LONG m_x at +0x16 and LONG m_y at +0x1A (the two
LONGs unaligned, as the binary has them). It is built by the receive
dispatcher 0x4EE020 (the ctor 0x4F5BF0) and by CGameAIBase::PlaySound's
send branch, which the port leaves as a NOTE (multiplayer is removed,
docs/adr/0002-single-player-only.md; under the null provider
m_bConnectionEstablished is never true, so the block cannot run).

## Body

`__thiscall void MarshalMessage(BYTE** pData, DWORD* dwSize)`, 518 bytes,
`ret 8`. The original constructs an unused CAIObjectType local at entry
(0x503AA0-0x503AC0; the port notes it). Share the target: on success its
remote pair goes out; on failure the pair is (0, 0xFFFFFFFF) and the body
continues -- the size is **not** zeroed. Copy m_cResSound to a CString,
size = resref length + 0x12, write the pair, the length byte and resref,
then m_nChannel, m_x and m_y; the closing assert is `cnt == *dwSize`
(0x503C7F).
## Wire format

Payload (without the 3-byte SPEC_MSG_HEADER): the target's remote pair
(PLAYER_ID m_remotePlayerID, LONG m_remoteObjectID; (0, 0xFFFFFFFF) when the
target does not resolve), a BYTE resref length and the resref bytes, then
the BYTE channel, LONG m_x and LONG m_y; the size is resref length + 0x12.
The unmarshal builds the resref and keeps an unresolved target as
INVALID_INDEX (TRUE).
