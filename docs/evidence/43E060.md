# 0x43E060 CMessageDisplayText::GetMsgSubType

## Asm

```
  43e060:	mov    al,ds:0x84cee7
  43e065:	ret
```

## Notes

- Returns CBaldurMessage::MSG_SUBTYPE_CMESSAGE_DISPLAY_TEXT, the BYTE at
  0x84CEE7 (0x10, 16). The subtype table at 0x84CED7 holds 0, 1, 2, ... so
  0x84CEE7 is index 16; 0x84CEE6 (15) is MSG_SUBTYPE_CMESSAGE_CUT_SCENE_MODE_STATUS.
- Ours returned the cut-scene status subtype (15) until 2026-11-24; a peer
  dispatching on the subtype would have decoded a broadcast DisplayText as
  the wrong class. Found while porting the receive side (#142).

## Test

`tests/test_message_display_text.cpp` checks `GetMsgSubType() == 16`; the
oracle case `messages-43E060` (`oracle/cases/messages.cpp`) compares ours
with the original's constant on the Windows oracle host.
