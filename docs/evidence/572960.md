## Notes

The argument list is `std::list<LONG>&`; the local list is the kept set.

- `_rand` is drawn **before** the target walk: `rand() & 3` plus the signed
  fixup is `rand() % 4`, then `inc ebx` makes the count 1 to 4.
- Per target: share (`THREAD_ASYNCH`, `INFINITE`), failed share skipped, a
  non-sprite released and skipped.
- The sprite id is inserted into the local list (`InsertNewNodeAfter` at
  0x572A44) **before** the animal test. Then
  `IcewindMisc::IsAnimal(object)` (`m_typeAI.m_nGeneral == G_ANIMAL`) is
  called: true increments the found count and, once it equals the drawn
  count, releases the current share and leaves the walk; false falls through
  to the ordinary release.
- Consequence, kept as observed: a sprite that is **not** an animal but
  precedes the Nth animal is already in the kept list, so the base strike is
  applied to it too. When the list has fewer animals than the count, every
  sprite is kept. Ids that cannot be shared and non-sprites are not kept.
- The kept list is handed to `CProjectileArea::ApplyToTargets` (0x5701B0),
  which is the only virtual call into the secondary path.

The port replaces the MSVC6 list internals with `std::list<LONG>` (same
insertion order) and keeps the draw-before-walk order, the insertion before
the type test and the exact stop condition.
