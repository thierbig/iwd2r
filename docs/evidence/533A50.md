## Notes

- `decw` leaves no usable sign information, and the follow-up compare is a signed `jg`, so a lifetime that wraps 0 → 0xFFFF reads as −1 and the cell removes itself the same round — `static_cast<SHORT>(...) <= 0` is exactly that test.
- The time-stop gate reads the caster id, not the source: cells spawned by a sprite that is also the time-stopper keep animating during a Time Stop, which is how the game renders ongoing sprays under the pause.
- The exe never re-reads +0x2A0 after `decw` before the vcall, so the decrement strictly precedes FrameAdvance — the port keeps that order.
