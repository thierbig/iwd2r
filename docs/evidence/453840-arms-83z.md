# 0x453840 CGameAIBase::EvaluateStatusTrigger, Task 83z arms

The dispatcher itself is 453840.md; this file records the eight small arms

## Arm notes

- 0x4082 completes the NumCreature-minus-party trio 83y started: the
  same seven GetAllInRange arguments in the same interleave, list count
  minus GetNumCharacters(), and a third final normalizer -- equality
  through the shared tail at 0x45451D for 0x4080, setl entering the
  0x4551AF block for 0x4081, inline setg for 0x4082. The port is the
  one case body with all three labels picking the test by trigger ID.
- 0x4019 and 0x401A ReputationGT are the same arm twice, one apart in
  the listing (0x45497D / 0x4549FD): identical party test and
  reputation loads, equality (sete) against setg. The port shares the
  body with both labels, as the trio does.
- The Reaction trio is byte-identical up to the final compare (sub/
  neg/sbb/inc at 0x455540, setg at 0x4555B7, setl at 0x45562C) -- the
  83s LevelGT/LT shape. All the substance sits in the stubbed
  0x45D560, so the port keeps the sprite resolution and the null early
  epilogue live and answers FALSE for all three, one TODO covering the
  three call sites.
- 0x40E5's two FALSE exits differ: a null cause or an out-of-1..6
  specifics jumps to 0x45AB39 (result zero, then the release tail --
  an empty release here since nothing was resolved into the slots).
- 0x4076 is the batch's only inversion: a zero specifics asks "is
  closed", the flag through the sub/neg/sbb/inc tail at 0x456BF2,
  while any nonzero specifics answers the open flag as it is.
- 0x40AF's two reads promote differently against the LONG specifics --
  the static's sequence id is a WORD zero-extended (0x4589DA), the
  sprite's a SHORT sign-extended (0x4589BB) -- which C++ integer
  promotion reproduces in a plain ==. The type dispatch is two
  independent gates, not an else-chain, matching the listing's
  fall-through to the release tail for every other type.
