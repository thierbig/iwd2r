# 0x71E760 CGameSprite::sub_71E760

Member of CGameSprite in the original's GameSprite.cpp, `__thiscall`
`void sub_71E760(CDerivedStats& DStats, int bFeedBack)` (the second

## Body

The original unrolls eleven identical arms for class types 1 through 0xB;
the port spells them as one loop (the arm bodies are byte-identical
modulo the constant). Each arm: if `m_derivedStats.GetClassLevel(n)` is
nonzero, call `ApplyClassAbilities(n, m_derivedStats.GetClassLevel(n) -
DStats.GetClassLevel(n), bFeedBack)` — the level delta is what makes
0x722D50 walk only the newly gained rows.

The tail: `nDiff = (BYTE) m_derivedStats.m_nLevel - (BYTE)
DStats.m_nLevel` (0x71E998-0x71E9A7 reads both bytes zero-extended, so
the diff is the unsigned wrap of the two levels); while positive, every
iteration raises `m_baseStats.m_resistMagicBase` (this+0x5F5) when the
race is elf (2) or gnome (6) and the subrace byte is 1 — drow and
svirfneblin gain 1% magic resistance per level gained. A non-positive
diff skips the loop entirely, so a lost level subtracts nothing.
