## Port notes

The signature is `LONG GetNearestTravelTrigger(LONG startObject, SHORT range, const BYTE*
terrainTable, BOOL checkLOS)`. The range limit starts at `range * range + 1`.
A failed initial share, a caller not on LIST_FRONT, or a failed visibility
check returns INVALID_INDEX. The LIST_FRONT exit (0x46CAC4) jumps past the
release and leaves the caller's share unreleased in the original; the port
keeps that. The caller type and its list position are read
but not used. With checkLOS, a party caller needs IsTileVisible and another
caller needs IsTileExplored; PointToTile and its SHORT truncation are inlined
in the original.

The scan begins at the **back list's** head (`CGameArea + 0x9AE`, head at
+0x9B2). This surprising list selection is explicit at 0x46CBCE and is kept.
Each successfully shared object with a list position is measured in x and
4/3-scaled y. Candidates must already beat the best y distance and be a
TYPE_TRIGGER whose m_triggerType is 2; with checkLOS they also pass CheckLOS
(start, candidate, terrainTable, TRUE). The full squared distance updates the
best id only on a strict improvement. Every successful candidate share is
released. The helper returns INVALID_INDEX when none qualifies.

The declaration and body were added only because EscapeArea directly calls
this previously unnamed code. The AR1000 tests use checkLOS FALSE, as the
handler does. The TRUE visibility/CheckLOS branch is established by the full
instructions above but is not independently data-tested; no oracle/emulator
result is claimed.
