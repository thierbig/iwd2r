action plus a point chosen with `rand()` (an oracle case would have to build an original sprite and
area). Proof is the Catch2 data test `sprite: RandomFly queues the fly arc, rounds the facing and

arc-branch seed each draw exactly three values and queue the RANDOMFLY and SETTARGETFLY actions

with the sprite above the area corner every try fails, exactly 3000 draws happen and the sprite is
jumped to a point inside the area with only the RANDOMFLY queued.
