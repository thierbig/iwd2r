# 0x75A4B0 CGameSprite::Berserk

Member of CGameSprite in the original's GameSprite.cpp, `__thiscall`
`SHORT Berserk()`, 1543 bytes (0x75A4B0-0x75AAB1). Ported in commit
15c9c04d.

## Body

Entry spends one tick of the action's duration
(`m_curAction.m_specificID--`) and answers ACTION_DONE when berserk is
off or the duration is spent (`<= 0`); the berserk flag is checked first
(0x75A4CE tests +0x722E before the counter). Otherwise a shared
CAIObjectType (frame -0x15C) and a default CAIAction (strings from the
global empty CString 0x8C5CF8) are built, and `rand() % 100 < 25`
(0x75A5C2) picks the arm:

- 25% arm: GetNearest(m_id, ANYONE (0x8C7748), GetVisualRange()
  (vtable+0x98), m_terrainTable (+0x50BB), TRUE, GetCanSeeInvisible()
  (vtable+0xB4), FALSE, 0, FALSE); only on a found target does
  AddAction(m_curAction) run (vtable+0x74, 0x75A70E) and the action
  become CAIAction(ATTACK (0x84778A), type patched with
  m_nInstance = target, 0, 0, 0) — the ctor inlined, including its
  create-destroy quirk instance.
- 75% arm: CAIObjectType enemy = m_typeAI.GetEnemyOf() (frame -0x120,
  dtor'd in the common tail), GetNearest with `enemy` as the filter, and
  AddAction(m_curAction) UNCONDITIONALLY; INVALID_INDEX (0x851878)
  routes to `action = 0x75AAC0(WAIT (0x8477F0), 6)` (CAIAction::CAIAction(SHORT, LONG),
  ported in Task 86a), a found target patches the shared type
  and assigns from the real 0x408E80 call.

The common tail dtors the temporaries, AddAction(action) (0x75AAA1),
and every path returns ACTION_DONE (0x8485C4) as SHORT.

## Callers

The case 124 arm of CGameSprite::ExecuteAction (0x72A3E3-0x72A3F3),
wired in the same commit; the arm returns what Berserk returns.

## Test

Driven directly in tests/test_sprite_actions.cpp [ai][data]: berserk off
with duration 5 spends one tick (4 left) and answers ACTION_DONE with
nothing queued; berserk on with duration 1 runs the counter to 0 and
also answers ACTION_DONE. The rand()/GetNearest arms are not asserted —
which arm runs depends on rand(), and on a found target the queued
action count differs (1 vs 2).
