# 0x4EDF60 CtrlAltDelete_JeffKAttacks

A debug console "CtrlAltDelete:" cheat-command handler, free function
taking nothing (`ret`), 31 bytes (0x4EDF60-0x4EDF7E). Ported in commit
(see report).

## Body

Reserves a stack slot, copy-constructs a CString from the "JeffK"
literal at 0x8ABDFC (0x7FCC88) into it, then calls
CtrlAltDelete_CreateCreature (0x4EC390) with ecx restored from esi and
esp+0 holding the string. The port:

```cpp
CtrlAltDelete_CreateCreature(CString("JeffK"));
```

## ecx / calling convention

ecx is saved into esi at entry and restored for the 0x4EC390 call,
which never reads it. Free function.

## Callers

Not in tree: the console dispatcher 0x5838A0 (deliberately unported;
docs/followups.md).

## Test

None: funnels into CtrlAltDelete_CreateCreature, which needs a loaded
area and a real creature file. Verified against the listing above.
