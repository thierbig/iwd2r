## Notes

(the count is one d4 drawn before the walk; the target type predicate is
`m_typeAI.m_nGeneral == G_UNDEAD`).

- Failed share skipped; non-sprite released and skipped.
- The sprite id is inserted into the kept list **before** the undead test
  (0x573374). The test's true branch increments the found count and stops the
  walk at the drawn count (releasing the current share first); its false
  branch falls through to the ordinary release.
- Consequence, kept as observed: a living sprite before the Nth undead is
  already in the kept list and is struck too, and with fewer undead than the
  count every sprite is kept. This is the same insertion-before-test shape
  as Hold Animal, not an extra filter.
- The kept list is handed to `CProjectileArea::ApplyToTargets` (0x5701B0).
