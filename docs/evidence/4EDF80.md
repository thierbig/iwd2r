# 0x4EDF80 CtrlAltDelete_JeffKDefends

A debug console "CtrlAltDelete:" cheat-command handler, free function
taking nothing (`ret`), 31 bytes (0x4EDF80-0x4EDF9E). Ported in commit
(see report).

## Body

Same body as CtrlAltDelete_JeffKAttacks (0x4EDF60) with the "JeffK2"
literal at 0x8ABE04: reserves a stack slot, copy-constructs the CString
(0x7FCC88) into it, then calls CtrlAltDelete_CreateCreature (0x4EC390)
with ecx restored from esi. The port:

```cpp
CtrlAltDelete_CreateCreature(CString("JeffK2"));
```

## ecx / calling convention

ecx is saved into esi at entry and restored for the 0x4EC390 call,
which never reads it. Free function.

## Callers

Not in tree: the console dispatcher 0x5838A0 (deliberately unported;
docs/followups.md).

## Test

None: funnels into CtrlAltDelete_CreateCreature, which needs a loaded
area and a real creature file. Verified against the listing above.
