# 0x453840 CGameAIBase::EvaluateStatusTrigger, Task 83u arms

The dispatcher itself is 453840.md; this file records the eight small arms
Task 83u ported, in commits 77f31fa6 (0x4037, 0x4038, 0x4064, 0x4065) and
eec020df (0x407E, 0x40DD, 0x40EA, 0x40EB). Register roles as in the other
arm batches: edi = this (mov edi, ecx at 0x453869) and ebx = 0 (NULL),
esi = bResult, the decoded CAITrigger copy at [esp+0x34], pSprite/pObject
at [esp+0x10], pObject2 at [esp+0x18], bNoRelease at [esp+0x28]. Seven of
the eight arms resolve the trigger sprite through the vtable+0xA4 call and
can leave through the early epilogue 0x45AB7A when it comes back NULL
(nothing shared, returns FALSE); their compare tails either fall into the
release tail 0x45AD4C (`mov eax, esi`) or jump into one of the shared setg
/setl tails other arms also use. The eighth arm (0x407E) resolves nothing
and takes a raw compare result all the way to the release tail.

## Arm notes

- 0x4037/0x4038 load the same mask and state word; the only difference is
  the normalizer (neg/sbb/neg answers nonzero 1, neg/sbb/inc answers
  zero 1). The port keeps one case body with the trigger ID picking the
  test, as LevelGT/LevelLT (0x4095/0x4096) already do.
- 0x4064's compare is byte vs byte with setne: TRUE when any non-fist
  weapon slot is selected.
- 0x4065 is HappinessGT's (0x4066) loads with the equality normalizer.
- 0x407E stores CompareStrings' raw eax into esi and never normalizes:
  the dispatcher's answer is the compare itself, 0 (strings equal) or
  the lstrcmpi difference. The port returns _stricmp's value the same
  way. Both CString temporaries are destroyed before the release tail.
- 0x40DD subtracts base from derived as signed shorts (movsx both), so a
  wounded sprite's lost amount is positive; the shared setl block it
  jumps into (0x4551AB) is the same one the HP arms use, entered one
  instruction in at 0x4551AF.
- 0x40EA/0x40EB share their loads exactly (sprite, GetClassLevel of
  int1) and differ only in the tail: setg at 0x459A21 versus setl at
  0x456AA3 -- the very tails LevelGT/LevelLT (0x4095/0x4096) use. No
  helper was invented for the pair; one case body picks the test by
  trigger ID, with a comment saying so.
