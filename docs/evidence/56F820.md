## Notes

Ported as CProjectileArea::Fire (slot 0x6C). Nothing without an area. Stores source, target and area; a share of the source retried on SHARED and DENIED (failure returns). With effects, the duration is GetDuration (slot 0x8C) of the last effect's byte +0xC4, `m_casterLevel` (0x56F898-0x56F8A7 walks to the list's tail and reads `BYTE [ecx+0xC4]`; the port first read the next field, now `m_spellPenetrationBonus`, and was corrected when the stats-spell rename exposed it). The start is the source's launch point (GetSourcePosition 0x52A640) when it travels, else the target point. Adds itself to the object array (on failure it deletes itself and releases the source); CGameObject::AddToArea(area, start, DetermineHeight(source), LIST_FRONT); the fire sound; the target point, position and exact position; the 4/3-scaled distance ftol(sqrt(d)+0.5): 0 arrives at once, else the velocity (d << 10) * speed / distance and the direction. Releases the source. Tested by tests/test_projectile.cpp.
