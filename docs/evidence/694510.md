# 0x694510 CScreenWorld::BeginChatMessage

`CScreenWorld` method, `thiscall`, 267 bytes (0x694510-0x69461B). The
name follows what the body does on the chat key: it re-opens the
interface and empties the chat edit so the player can begin typing a
message.

## Body

Two early gates: the session-open byte
(`g_pBaldurChitin->cNetwork.GetSessionOpen()`, [0x8CF6DC]+0x1032 at
0x694519, `je` 0x694521) and the provider
(`g_pChitin->cNetwork.GetServiceProvider()` == SERV_PROV_NULL,
[0x8CF6D8]+0x96E vs [0x85E65C]=0 at 0x69452D-0x694539). A
single-player host session — session open, null provider — returns at
the second gate, which is why both call sites carried "unreachable
here" NOTEs until this port.

Then the chat bar panel itself must be active
(`GetManager()->GetPanel(22)->m_bActive`, 0x69453F-0x69455A), else
return. If the world manager is hidden ([eax] at 0x694574, CUIManager
m_bHidden at offset 0), the auto-hide flag clears (byte [esi+0x11CA],
0x694579) and UnhideInterface() runs (0x694580-0x69458F).

The panel for the edit is picked by re-reading both session gates
(0x694590-0x6945B4): chat bar (22) when both still pass, main panel
(0) otherwise. The control carrying the edit is 5 on panels numbered
19 and 21, 3 on panel 22, none anywhere else (0x6945D6-0x6945ED). With
no control found the function returns; otherwise the empty string goes
by value through vtable +0x70, CUIControlEdit::SetText
(0x69460C-0x694615), via the tree's cast idiom
`static_cast<CUIControlEdit*>(pPanel->GetControl(nControl))`.

## Caller

Wired at both CScreenWorld::OnKeyDown (0x6872D0) keymap-24 sites
(src/CScreenWorld.cpp), in exe order — 0x694510 first, then 0x693710
(`sub_693710`) — replacing the NOTEs at both sites.

## Test

tests/test_sp_host.cpp [sp-host][chat] pins the two early gates. Both
precede every panel access, so the observable is the state the unhide
arm would clear: the manager hidden and m_nAutoHideInterface armed
stay untouched after the call, first with no session, then under the
null-provider host session the harness opens.
