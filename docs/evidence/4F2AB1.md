## Consequence

The exe can construct and unmarshal the class with its four-argument ctor
and the two public overrides. Our tree does not port the network receive
dispatcher (CMessageHandler::AsynchronousUpdate's receive path is documented
as omitted for single player), so no factory source case exists or is added;
the shared mechanism this class needs is simply the public ctor plus
Unmarshal/Run, which src/CMessage.cpp now provides.
