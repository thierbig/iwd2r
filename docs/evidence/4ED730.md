# 0x4ED730 CtrlAltDelete_CheckVar

A debug console "CtrlAltDelete:" cheat-command handler, free function
taking two by-value CString arguments (`ret 8`), 757 bytes
(0x4ED730-0x4EDA25, `ret 8` at 0x4EDA22 then alignment padding to
0x4EDA30). Named for the CHECKVAR console word: the dispatcher's
command-word resolver (0x583E60) matches the obfuscated literal that
decodes to "CHECKVAR", maps it to id 0x12, and dispatch arm 5
(0x583B26) calls here from 0x583B77 once CountArgs (0x584420) reports
exactly 2, handing the handler this+0x38 in ecx. Ported in commit (see
report).

ecx is saved in ebp on entry and re-loaded into ecx for the single
shared print tail's call to CtrlAltDelete_DisplayText (0x4EC1C0 at
0x4ED9DE); that callee never reads it, so the port is a free function.
