# 0x45B610 CInfGame::sub_45B610

A tiny `__thiscall` on CInfGame sitting between GetOptions 0x45B5F0 and
GetReputation 0x45B640 (29 bytes, `ret 4`). Ghidra leaves it auto-named;
the port keeps the address-derived name sub_45B610, the 45B290.md
precedent. Ported as the IsPlayerNumber arm's (0x40E5) slot read in
Task 83z, commit da9c5346; the evidence for that arm is
453840-arms-83z.md.

## Listing

```asm
0x45b610: mov  ax, word ptr [esp + 4]     ; SHORT nPlayer
0x45b615: cmp  ax, 6
0x45b619: jl   0x45b623
0x45b61b: mov  eax, dword ptr [0x851878]  ; CGameObjectArray::INVALID_INDEX
0x45b620: ret  4
0x45b623: movsx eax, ax                   ; sign-extended index
0x45b626: mov  eax, dword ptr [ecx + eax*4 + 0x3816]  ; m_characters[n]
0x45b62d: ret  4
```

The signed `jl` on the raw SHORT takes the array read for anything
below 6 -- the port's `if (nPlayer < 6)` -- and the out-of-band read is
the INVALID_INDEX global our tree already carries
(CGameObjectArray::INVALID_INDEX, src/CGameObjectArray.h). The array is
m_characters[6] at +0x3816 (src/CInfGame.h:488).
