# 0x4FD1D0 CMessageDoorOpen::Run

Deny-lock m_targetId (retry while SHARED/DENIED); on SUCCESS, if the door's m_dwFlags bit 0 differs from m_bOpen, share-lock m_sourceId the same way and, on SUCCESS, type.Set(source->GetAIType()) (virtual slot 0x10 at 0x4FD2DF), door->ToggleDoor(type, FALSE), release the share; release the deny either way. The port clears the asm red by spelling every callee the binary names (GetDeny 0x599C70, GetShare 0x599A50, ReleaseShare 0x599E70, ReleaseDeny 0x59A010, CAIObjectType ctor/Set, ToggleDoor 0x489680); only the implicit CAIObjectType dtor (CString_Destruct 0x7FCC1A at scope end) remains macro/implicit, which the tool accepts.
