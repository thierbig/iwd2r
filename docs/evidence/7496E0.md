## Notes

The port preserves the exact result distinctions: missing/unusable equipment,
no share, no enemy near the point and an enemy outside pursuit all answer
INTERRUPTABLE; queuing a return move and encumbrance feedback answer DONE; an
in-range `Swing` result passes through; and a pursuit `MoveToObject` DONE or

followed by Swing's re-armed attack frame. It passed 21 assertions in one test
case, with one `NewGame` call. Other branches above are disassembly-verified,
not measured against a running original.
