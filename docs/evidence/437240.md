## Notes

1. The guard is the client's: the session must be open and this machine must not host
   (chitin+0x1032/+0x1033); the host name comes from the inlined
   `CNetwork::GetHostPlayerName` (`m_nHostPlayer == -1` -> "", else `m_psPlayerName[n]`) and an
   empty name aborts the send.
2. The original sets `al` to 1/0 (a BOOLEAN return in its source); the imported header declares
   the function void (as with `WeatherBroadcast`), so the port keeps void.
3. The allocation/free is the file's `CreateBuffer`/`DestroyBuffer`; the send's FALSE from the
   dead DirectPlay path is ignored.
