## Body

`__thiscall BOOL UnmarshalMessage(BYTE* pData, DWORD dwSize)`, 347 bytes,
`ret 8`. Resolve the target pair through CGameRemoteObjectArray::Find; a
miss stores INVALID_INDEX and decoding continues (0x4FC3C0-0x4FC3DE). Read
a SHORT name length, build m_name with CString_ConstructWithLength, read a
SHORT text length after the name and build m_text the same way
(0x4FC3E0-0x4FC46A), then copy m_nameColor, m_textColor, m_marker and
m_moveToTop (0x4FC46A-0x4FC490). The closing assert is
`cursor == dwSize`. The original builds both CStrings from the wire
lengths without checking them against dwSize, so the port bounds the copies
to the packet (P4-10) while keeping the wire lengths for the cursor.

length and the text bytes, the two COLORREFs, LONG m_marker and BOOLEAN
m_moveToTop.
