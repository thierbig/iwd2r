# 0x45C290 CGameAIBase::sub_45C290

Member of CGameAIBase in the original's GameAIBase.cpp, `__thiscall`
`CGameObject* sub_45C290()`, 110 bytes (0x45C290-0x45C2FF). Ported with the
case 281/305 arms that call it.

Ghidra shows only the auto-name `CGameSprite_B3AUTO_0045c290` (the class in
the original's PDB is CGameSprite, whose methods this dispatcher belongs to
by address range; the body touches CGameAIBase members through ecx), so the
tree keeps the address-derived name, as it does for sub_4530F0/sub_453110.

## What it does

Resolves `m_curAction.m_acteeID` (this+0x4B4) through
`CAIObjectType::sub_40CCA0(this, FALSE)`; if the object is a sprite whose
`m_derivedStats.m_cImmunitiesAIType` (sprite+0xAE0) lists this base's
`m_typeAI` (this+0x20), releases the share and forgets it. Then
`SetTargetObject(pObject)` and return the object. It is exactly the head of
`GetTargetShareType` (0x45BDD0) -- actee resolve, immunity release,
SetTargetObject -- without the type-mismatch and blind-reach filters that
follow there, and with a single SetTargetObject call.
