# 0x57C1D0 IcewindCProjectileScorcher::Strike

## Decompiled (anchored on the exe; dependency of bundle row 0x57BE80)

The driver bundle carries nothing for this address — GatherTargets (the
0x57BE80 row) dispatches it through vtable slot +0x8C, so it is imported as
a dependency, anchored on the exe bytes (see exemption). What the exe does,
in order:

1. Shares the target out of the game object array (`GetShare(target,
   THREAD_ASYNCH, &victim, INFINITE)`); anything but the SUCCESS byte
   returns without releasing anything.
2. A victim without the TYPE_AIBASE object-type bit releases the target and
   returns.
3. A sprite victim is tested with `IsTargetImmune(this, victim)` (the
   0x536FC0 dependency); an immune one gets
   `FeedBackImmuneToResource(victim, m_sourceRes)` and a target-only
   release before returning.
4. Otherwise the source is shared the same way (its failure releases only
   the target), the wave origin is computed with
   `GetSourcePosition(m_sourceId, &origin, TRUE)`, and the check is
   `CheckLOS(origin, victim->GetPos(), m_terrainTable, FALSE)` on the
   projectile's area.
5. With line of sight, the source sprite's resref effects for `"EffAS1"`
   (initial wave) or `"EffAS2"` are gathered at level 1; every effect gets
   its source resref stamped `"SpWi217"` and is handed to the target as a
   `CMessageAddEffect(effect, m_sourceId, target)` through the message
   handler, `AddMessage(message, FALSE)`.
6. Tail: `ReleaseShare(target)` then `ReleaseShare(m_sourceId)`.

`ret 0x8` — LONG target plus BYTE initial, this in ECX.

void IcewindCProjectileScorcher::Strike(LONG target, BYTE initial)

    CGameObject* victim;
    if (objects->GetShare(target, CGameObjectArray::THREAD_ASYNCH, &victim, INFINITE)
        != CGameObjectArray::SUCCESS) {
        return;

    if ((victim->GetObjectType() & CGameObject::TYPE_AIBASE) == 0) {

        return;

        objects->ReleaseShare(target, CGameObjectArray::THREAD_ASYNCH, INFINITE);
        return;

    if (objects->GetShare(m_sourceId, CGameObjectArray::THREAD_ASYNCH, &source, INFINITE)
        != CGameObjectArray::SUCCESS) {
        objects->ReleaseShare(target, CGameObjectArray::THREAD_ASYNCH, INFINITE);
        return;

            g_pBaldurChitin->GetMessageHandler()->AddMessage(message, FALSE);
        }
    }

    objects->ReleaseShare(target, CGameObjectArray::THREAD_ASYNCH, INFINITE);
    objects->ReleaseShare(m_sourceId, CGameObjectArray::THREAD_ASYNCH, INFINITE);
}
