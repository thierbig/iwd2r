# 0x4ECA80 CtrlAltDelete_SetAreaExplored

A debug console "CtrlAltDelete:" cheat-command handler, free function
taking nothing (bare `ret` after the tail jump), 37 bytes
(0x4ECA80-0x4ECAA4). Ported in commit (see report).

## Body

Takes the game from g_pBaldurChitin+0x1C54 (spelled `GetObjectGame()`
in the port), zero-extends the visible-area index byte at +0x37E0,
loads the area pointer from the pointer array at +0x37E2 (the tree's
`GetVisibleArea()`), adds 0x860 — CGameArea::m_visibility
(CGameArea.h:297) — and tail-jumps to `CVisibilityMap::SetAreaExplored`
(0x553740, CVisibility.cpp:1131). The port:

```cpp
g_pBaldurChitin->GetObjectGame()->GetVisibleArea()->m_visibility.SetAreaExplored();
```

## ecx / calling convention

ecx is zeroed for the index extension and reloaded, never read as a
this. The `jmp` makes the callee's frame the handler's own. Free
function.

## Callers

Not in tree: the console dispatcher 0x5838A0 (deliberately unported;
docs/followups.md).

## Test

None: the callee walks a visibility map of a loaded area, which no
unit test owns. Verified against the listing above.
