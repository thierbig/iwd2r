# 0x576150 CProjectileArea8507C8::Fire

Vtable slot 0x6C of the one-shot area strike (class documented in
docs/evidence/576080.md). The landing: register with the object array,
resolve the source's position, join the area, play the fire sound, store
the positions. What is *gone* relative to the base
`CProjectileArea::Fire` (0x56F820) is as telling as what remains — no
effect list is read, no duration is stored, `m_bTravels` is not
overridden, and the travel/direction tail does not run. `[markers]
yellow: no function defined here`: 0x576150 is unlabelled in
functions.tsv (the same gap 0x5752E0 had), so the marker comment is the
only label.

## Disassembly walkthrough (fresh, this task)

- `test edi,edi; je end` — the pArea null check; stores m_sourceId
  ([esi+0x72]), m_targetId ([esi+0x76]), m_pArea ([esi+0xEA]).
- Source `GetShare` 0x599A50 (THREAD_ASYNCH byte 0x851873, INFINITE),
  retried while the result is SHARED (0x851870) or DENIED (0x851871);
  any other failure is a plain return. NOTE: the pSource out-param is
  fetched and never used.
- `GetSourcePosition` 0x52A640, cdecl 3 args (m_sourceId, origin CPoint
  out, TRUE) with the caller-side `add esp,0xC` — thiscall callees pop
  their own args, cdecl do not.
- `Add` 0x59A0F0(&m_id at [esi+0x5C], this, INFINITE). On failure:
  `mov edi,[esi+0x72]` caches m_sourceId *before* `call [edx]` (delete
  this, push 0x1), then `ReleaseShare` 0x599E70 of the cached id and
  return — the base Fire's failure shape.
- On success `mov eax,[esp+0x1C]` hands **pArea**, not pSource, to
  `DetermineHeight` 0x529F40 (stack-depth: the LIST_FRONT byte
  [0x84C50C] pushed at 0x57624F sits *below* DetermineHeight's argument
  and survives it — DetermineHeight is thiscall and pops its one
  argument — to become `AddToArea` 0x4C7BE0's fourth). Net:
  `AddToArea(pArea, &origin, DetermineHeight(pArea-as-sprite),
  LIST_FRONT)`. NOTE kept in the port.
- `PlaySound` 0x52A4E0(m_fireSoundRef [esi+0x152] by value — two
  dwords — m_loopFireSound [esi+0x15A], FALSE).
- The tail stores in exe order: m_posExactX [esi+0x9C] = origin.x <<
  RESOLUTION_INC (WORD [0x85EB66], read 10); m_posExactY [esi+0xA0] =
  ((origin.y << 10) << 2)/3 via the `imul 0x55555556` signed-divide-3
  magic; m_targetPos.x [esi+0xC8]; m_pos.x [esi+0x6]; m_pos.y [esi+0xA];
  m_targetPos.y [esi+0xCC].
- Final `ReleaseShare` 0x599E70(m_sourceId, ASYNCH, INFINITE);
  `ret 0x1C` — seven stack args: pArea, source, target, targetPos.x,
  targetPos.y, nHeight, nType (the last two unused by the body).

## Branch inventory

The null check, the two GetShare retry loops, the Add failure branch —
all ported. The rest of the conditionals are SEH state stores. No
operator-new of the decoder's kind runs here.

## Port

src/CProjectile.cpp, `// 0x576150`: the base-Fire shape
(src/CProjectileArea.cpp `CProjectileArea::Fire`) minus the effect list,
duration store, m_bTravels override and travel/direction tail, with the
pArea-to-DetermineHeight reinterpret_cast NOTE and the failure path's
cached-id release. nHeight/nType are named and unused, as in the base.

## Test

("the plain area effects decode straight to their ctors") — the override
