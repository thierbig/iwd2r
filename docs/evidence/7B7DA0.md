# 0x7B7DA0 GLSetupProbeDriver

Imported from the WSO fork body (see the commit trailer); read against the disassembly of IWD2.exe. New code block in src/CChitin3d.cpp (the engine-side half of the GLSetupSelectDriver import).

Read against 0x7B7DA0-0x7BAABB: entry tears down any prior probe state with a call to GLSetupResetDriver (0x7BAAC0) at 0x7B7DAF, then reads the control byte at 0x9074AC. The FX_GLIDE_NO_SPLASH save/prime runs under control bit 0x10: getenv (call 0x7EA1F8) caches the current value at 0x9074B8 with the one-shot flag at 0x9074B4, then sprintf (0x7E8317) "%s=%s" with "FX_GLIDE_NO_SPLASH" (0x8BD544) and "1" (0x8A6DE0) is passed to _putenv (0x7EA143). The OverrideDispatch save/prime runs under bit 0x20: RegOpenKeyExA (import 0x847004) on "Software\Silicon Graphics\OpenGL" (0x8BD518), RegQueryValueExA (0x847000) caching the policy DWORD at 0x9074C0 with the flag at 0x9074BC, RegCloseKey (0x847008), then RegCreateKeyExA (0x847010) / RegSetValueExA (0x847014) prime the value. The co-location check normalizes both candidate paths with GetFullPathNameA (import 0x847124) and rejects with return 1 when the directories differ; LoadLibraryA (0x8472B8) loads the primary (0x906914), mini (0x906918) and gdi32 (0x906910) modules. The entry-point table is resolved with GetProcAddress (import 0x8472BC, loaded into ebp at 0x7B7FD5 and called indirectly throughout) over the OpenGL 1.1 / WGL / GLU names, storing into the g_pfnGLSetup* slots and the CVideo3d:: table from 0x907514, OR-ing a bMissing flag for each NULL; the tail resolves the remaining names from the mini handle at 0x906918 (e.g. 0x8BBDA4 -> 0x907AF4, 0x8BBD98 -> 0x907AF8, 0x8BBDB4 -> 0x907B1C), copies the mini path inline into 0x9073A8, and when bMissing is set calls GLSetupResetDriver (0x7BAA9D) and returns 2, else returns 0. The fork body spells every one of these steps in the same order; only its static linkage and its winver.h/mbstring.h build assumptions were adapted (non-static with forward declarations, file-local registry/_putenv shims that fail gracefully so the priming steps are skipped on this platform).
