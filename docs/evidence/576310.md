# 0x576310 CProjectileArea8507C8::GetTargets

Vtable slot 0x90 of the one-shot area strike (class documented in
docs/evidence/576080.md). Byte-for-byte the base
`CProjectileArea::GetTargets` (0x56FED0, ported at
src/CProjectileArea.cpp) except for exactly two operand bytes: both
gathers' line-of-sight flag is FALSE where the base passes TRUE.

## Disassembly walkthrough (fresh, this task)

- `CTypedPtrList<CPtrList, LONG*> found` built by 0x40A110(10).
- The dual gather off m_pArea — `GetAllInRange` 0x46CD20 with
  m_posVertList, m_pos, m_targetType, m_nRadius, m_terrainTable, the
  list, **FALSE**, m_bCheckForNonSprites; `GetAllInRangeBack` 0x46D590
  with m_pos, m_targetType, m_nRadius, m_terrainTable, the list,
  **FALSE**, FALSE, m_bCheckForNonSprites. The two bold FALSE bytes are
  the only semantic diff from 0x56FED0 (the base's lineOfSight TRUEs);
  everything else — argument order, member offsets, the Back variant's
  ignoreDead FALSE, the anyone filter — is identical.
- The forget loop: walk m_targetHits, erase the ids no longer in found.
- The output walk: for each found id, default m_targetHits[id] to 0,
  emit it when `m_targetHits[id] % m_nHitModulus == 0`, then increment —
  the hit bookkeeping the base carries and this class keeps (its
  one-shot ApplyToTargets only ever consumes the first qualifying
  entry, so the bookkeeping is vestigial here, but the exe runs it all
  the same).

The remaining diffs against the base bytes are SEH scope-table
encodings and rel32 shifts — no code change.

## Branch inventory

Identical to the base function's: the two walk loops, the erase branch
and the modulus test, all ported in the copied body. The SEH state
stores are excluded as usual.

## Port

src/CProjectile.cpp, `// 0x576310`: the base body copied verbatim with
the two `TRUE,` lineOfSight arguments changed to `FALSE,`.
