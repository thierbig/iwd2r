## Notes

Ported as the slot overload `SHORT CGameSprite::DropItem(SHORT nSlot)`, 361
bytes (`0x754D70-0x754ED9`). It is distinct from the existing
`DropItem(CItem*)` at `0x7618E0`.

- Slot -1 returns ACTION_ERROR before looking up a ground pile. Failure of
  `GetGroundPile` or `GetDeny` also returns ACTION_ERROR. Once the deny has
  succeeded, the common tail releases it and returns ACTION_DONE, including
  when the slot is the fist, empty, or not droppable.
- Other slots are indexed without a new range check. A non-NULL item with
  file flag `0x4` is placed on the pile with `(TRUE, SHORT_MAX)`, then
  demanded. This order is visible at `0x754E29-0x754E43` and is kept.
- The selected weapon becomes `SLOT_FIST`, ability/feedback/retry `(0,0,1)`,
  when the dropped slot is selected. The same reset occurs when the current
  selected slot is in the first three ammo slots (`SLOT_AMMO` through
  `SLOT_AMMO + 2`, not all four) and the low byte of ability zero's type is 4.
  The cast to BYTE is required by `cmp byte ptr [eax],4` at `0x754E87`; a WORD
  comparison would miss values such as `0x0104`. As in the original,
  `GetAbility(0)` is dereferenced without a NULL check in that second arm.
- Afterwards the item is `ReleaseAll`ed, `Unequip(nSlot)` runs, and only then
  is the slot cleared. Nothing deletes the item here; placement has already
  handed it to the game's disposable-item list.

The focused action test covers the -1 and fist paths and a personal-inventory
drop through action 9. The combat regression `DropItem reads only the low
byte of a launcher's ability type` adds a real droppable item copy, patches
ability zero to `0x0104` while its resource is demanded, selects SLOT_AMMO,
and checks both the fist selection and the cleared slot. It re-demands the
resource to restore the original type after `ReleaseAll`, so no stale ability
pointer is written. No original-runtime oracle or emulator case was run; this
is an in-tree regression test against the recovered disassembly, not a
measurement of the original executable.
