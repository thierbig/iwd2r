## Test

The handler is not driven: every arm's first effects run through chitin
globals (WritePrivateProfileStringA on the live INI, CTlkTable::Fetch on
the live talk table — which derefs the live TLK resource — and
CScreenWorld::DisplayText), which the zeroed-stub pattern used by [clua]
and [ai] tests cannot stage. The CLUAConsole the console arm builds is
driven end to end by the [clua] suite (tests/test_cluaconsole.cpp), and
the inlined per-line construction is pinned as the ctor by the test
committed in e88196b02.
