# 0x5CDD00 CInfinity::DarkenRect

## What it is

The CInfinity half of the floating-text dark box: takes the world-space
rect, moves it to screen space like its sibling DrawHighlightRect
0x5CDDC0, and hands it to the video mode's DarkenRect (vtable slot
0xAC, ported this task as 0x797E70). Thiscall, `ret 4`:
`void DarkenRect(const CRect& rSquare)`. 180 bytes
(0x5CDD00-0x5CDDB4).

## Decode (annotate 0x5CDD00-0x5CDDB4)

- The argument rect copied to a local and `CRect::NormalizeRect`
  0x802641 called on it (0x5CDD2C) — the only named callee.
- rDst built from the normalized rect (0x5CDD31-0x5CDD6D):
  left = rViewPort.left [+0x48] - nCurrentX [+0x90] + r.left, top =
  rViewPort.top [+0x4C] - nCurrentY [+0x94] + r.top, right = left +
  (r.right - r.left), bottom = top + (r.bottom - r.top). No
  max(Width,1) — unlike DrawHighlightRect — and no
  ApplyFadeAmount/ApplyBrightnessContrast pass; the dark box bypasses
  both (the callee is a raw surface halving).
- rClip = (rViewPort.left, rViewPort.top, rViewPort.right [+0x50] - 1,
  rViewPort.bottom [+0x54] - 1) (0x5CDD71-0x5CDD89) — the same clip
  rect every CInfinity draw sibling builds.
- `esi = [esi+0x1C]` pVidMode; `call [vtable+0xAC]` with (rDst, 0,
  rClip) (0x5CDD7C-0x5CDDA4); the BOOL result is discarded. Surface
  argument 0 — the callee's hardcoded surface-0 unlock tail matches.

## Port

`src/CInfinity.cpp` between DrawEllipse 0x5CDC60 and DrawHighlightRect
0x5CDDC0, declaration in `src/CInfinity.h` alphabetically before
DetachVRamRect. Spelling mirrors DrawHighlightRect (rNormal, member
assignment into rDst/rClip). Parity: all columns green.

## Callers

CGameText::Render 0x4CBB20 at 0x4CBF22 — the floating-text render
calls it with the padded text bounds (wired this task).

## Tests

Not drivable in isolation: a CInfinity needs the engine's area state
(rViewPort/nCurrentX off a live WED). The callee 0x797E70 is covered
directly by the [vid] test in tests/test_vid.cpp; this wrapper's math
(rViewPort - nCurrent + r, clip right/bottom -1) is the same
construction as the already-tested siblings.
