# 0x797E70 CVidMode::DarkenRect

## What it is

The 50% dark box behind floating text. Thiscall on the CVidMode, `ret 0xC`:
`BOOL DarkenRect(const CRect& r, UINT nSurface, const CRect& rClip)` —
CVidMode vtable slot 0x00AC (between DrawRect 0x00A8 and OutlinePoly
0x00B0; the header's slot comments left the gap, filled by this port).
622 bytes (0x797E70-0x7980DD).

## Decode (annotate 0x797E70-0x7980DD)

- `IntersectRect(&local, &rClip, &r)` (USER32 via 0x8474D0); empty
  intersection returns FALSE (0x797E70-0x797EB0).
- The intersected rect clamped against the clip again by hand
  (max/max/min/min, 0x797EB7-0x797EF4) — idempotent since local = r n rClip
  is already inside rClip; dx = local.left - clamp.left and dy =
  local.top - clamp.top (0x797EF6-0x797F02) are therefore always 0, kept
  for the addressing.
- Column/row counts as (local.right - clamp.left) - dx and
  (local.bottom - clamp.top) - dy (0x797F08-0x797F70, the `sub esi, ebx`
  at 0x797F41) — the rect's own width and height either way.
- `DDSURFACEDESC ddsd; ddsd.dwSize = 0x6C;` then LockSurface(nSurface,
  &ddsd, clamp) at 0x799FA0; failure returns FALSE (0x797F7A).
- dwHalveMask = ((mR>>1)&mR) + ((mG>>1)&mG) + ((mB>>1)&mB) over the
  locked pixel format's masks at ddsd+0x58/+0x5C/+0x60
  (0x797F3E-0x797F66): 0x7F7F7F for 8-8-8. The mask sum is commutative,
  so which mask field is which channel never matters.
- `switch (g_pChitin->cVideo.GetBitsPerPixels())` (word at g_pChitin
  [0x8CF6D8]+0x7EA): 16 -> 0x798056, 24 -> 0x797FEB, 32 -> 0x797F98,
  default skips the loops straight to the unlock.
- All three loops start at lpSurface + lPitch*dy + dx*depth and advance
  rows by lPitch - cols*depth (hoisted at 0x797FB3/0x797FBB/0x798044):
  - 32 (0x797F98): `*(DWORD*)p = (*(DWORD*)p >> 1) & mask; p += 4`.
  - 24 (0x797FEB): eax = p[1]<<16 \| p[2]<<8 \| p[0], halved and masked,
    then a 4-byte store at p and p += 3 — the store's fourth byte is the
    next pixel's first byte, written with the value's top byte, which is
    0 after the mask, so every pixel after a row's first reads its low
    byte as 0. Ported as-is.
  - 16 (0x798056): `*(WORD*)p = (*(WORD*)p >> 1) & mask; p += 2`.
- Tail 0x7980AA: the inlined body of UnLockSurface 0x79A820 with index 0
  (m_nSurfaces != 0, pSurfaces[0] != NULL, Unlock(ddsd.lpSurface)), then
  `mov eax, 1` — surface 0 whatever nSurface was locked. Ported as
  UnLockSurface(0, ddsd.lpSurface) with a NOTE (DrawRect 0x7980E0's port
  deviated here; this one stays faithful, and the one caller passes 0).

## Port

`src/CVidMode.cpp` between DrawLine16 and DrawRect, declaration at the
0x00AC slot in `src/CVidMode.h`. Plain port, no render::Active() backend
hook and no 3D branch — the original has neither (unlike DrawRect).

Parity: 0 RED, 1 YELLOW (asm "only unresolved calls remain to confirm"):
the callee 0x11C in the export is the IntersectRect import thunk the
Ghidra export left unnamed; LockSurface 0x799FA0 is named. Data-side,
not waived.
