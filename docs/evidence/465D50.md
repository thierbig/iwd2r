# 0x465D50 CGameAIBase::AddexperiencePartyGlobal

Member of CGameAIBase in the original's CGameAIBaseActions.cpp,
`__thiscall` `SHORT AddexperiencePartyGlobal()`, 472 bytes
(0x465D50-0x465F27). Ghidra's CGameSprite_B3AUTO_00465d50 name is
wrong, same as its neighbors: the function reads `this` as a
CGameAIBase (m_curAction at 0x476, the sprite gate on the virtual
GetObjectType).

Ported in one commit, d5ad5364; the caller arm is the ExecuteAction
commit c5395808 (case 165 of 0x44DC10, 0x44FCBE-0x44FCCC:
`returnValue = AddexperiencePartyGlobal(); goto done`).

## Callers

Exactly one: the case 165 arm of CGameAIBase::ExecuteAction
(0x44FCBE-0x44FCCC), reached when a script queues
AddexperiencePartyGlobal(name, scope). Like 141 it routes through the
common done label, so the handler runs with no target share held.

## Callees

One callee not previously called from a ported CGameAIBase handler —
CInfGame::AddExperienceParty (the binary's AddPartyXP at 0x5C0BB0),
already ported in-tree at src/CInfGame.cpp:8684. Everything else is
the same in-tree lookup chain as GivePartyGoldGlobal (0x465220):
CAIAction::GetString1 and GetString2, CString::MakeUpper, strcmp,
CBaldurChitin::GetObjectGame, CInfGame::GetVariables, the virtual
GetObjectType, CGameSprite::GetLocalVariables, CVariableHash
::FindKey, CInfGame::GetArea, CGameArea::GetVariables.

## Notes

- The variable lookup is the same chain as 0x465220 — GetString1 the
  name, GetString2 the scope, both uppercased; GLOBAL the game
  variables, LOCALS the executing sprite's own (0 for a non-sprite),
  MYAREA the area name read as a C string from m_pArea, any other
  scope an area name — but without 0x465220's dead second LOCALS
  compare: here the else-if chain is GLOBAL / LOCALS / everything
  else.
- The missing-area path reads the same uninitialized spill slot
  ([esp+0x14] at 0x465ED5; no path to that instruction stores it).
  Bounded to 0 with a note, the same CScreenStore P4-10 precedent as
  0x465220.
- The amount goes straight to the game object through the chitin's
  m_pObjectGame field (chitin+0x1C54), not a GetObjectGame() call:
  AddExperienceParty(amount, FALSE, FALSE). With a FALSE challenge
  rating the game splits the amount among the living party members (a
  CMessageAddEffect experience effect, opcode 104, per member), so
  each member's effectAmount is its share, not the total. The return
  value of AddExperienceParty is ignored.
- Returns ACTION_DONE (word 0xFFFF at 0x8485C4).
