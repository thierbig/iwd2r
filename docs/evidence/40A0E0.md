## Port

already in src (e.g. `CMessageWeaponImmumityUpdate::GetMsgType`, same
label, same body): `return CBaldurMessage::MSG_TYPE_CMESSAGE;`. The
exe's single folded body is what every subclass shares at runtime;
source-level duplication is what the original source carried for the
linker to fold. Our tree adds the three missing copies so each new
class's vtable slot resolves to the same code.

- 0x43 = 67 matches our `MSG_TYPE_CMESSAGE` definition
  (src/CMessage.cpp:79) exactly.
- vtable slot 2 of each new class's vtable points here (dwords decoded
  above), so defining these copies is required for the classes'

- The fork labels this address with the same body our tree already
