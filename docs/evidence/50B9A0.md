## Notes

Identity: vtable 0x84D510 slot 0x14 (Marshal is slot 0x10, Run slot
0x18). The survey's row 103 names this address correctly.

Reverses the 0x50B680 record: resolves the target through the remote object
array (a failed Find stores -1 as the target and still succeeds, as the exe
does), zeroes the 51 equipment slots, restores the selected weapon, its
ability and the weapon set, then creates one CItem per wire item from its
resref, usage counts, wear and file flags. The function asserts that the
final read offset equals dwSize, which includes the three-byte spec header.

Not executed: no received message reaches it in the single-player build; the
test calls it directly with a packet MarshalMessage produced. No oracle
case or replay.
