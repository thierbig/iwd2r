# 0x5767A0 CProjectileArea850864::ApplyToTargets

Vtable slot 0x94 of the warrior-gated strike (class documented in
docs/evidence/576770.md). The filter in front of the parent's one-shot
strike: walk the gathered list, share each id, and keep only the sprites
whose AI type carries at least one of the four warrior class bits
(Barbarian 0x01, Fighter 0x10, Paladin 0x40, Ranger 0x80 — mask 0xD1).
Everything else is erased from the list before it is handed to 0x5765F0.

## Disassembly walkthrough (fresh, this task)

- `mov ebp,[esp+0xC]` — &targets; `mov esi,[head]` the first node; an
  empty list jumps straight to the tail delegate at 0x57685A.
- The loop (0x5767B9): target `GetShare` 0x599A50([esi+8] id,
  THREAD_ASYNCH 0x851873, &out, INFINITE); failure (≠ 0x85186C SUCCESS)
  → plain return at 0x576864 — NOTE: no release, and the parent strike
  never runs.
- `call [edx+4]` — `GetObjectType()` vs 0x31 (TYPE_SPRITE); non-sprite →
  jump to the loop bottom 0x57682C *without advancing esi* — NOTE: the
  node is re-shared and re-tested forever, a genuine spin in the exe
  bytes, unreachable because the gather it filters (0x576310) emits only
  sprite ids.
- Sprite: `call [eax+0x10]` — `CGameObject::GetAIType()` (0x44CB60,
  returns m_typeAI at +0x20); `test byte [eax+0x18],0xD1` —
  m_nClassMask & the four warrior bits.
- Bits present (0x576807): `mov esi,[esi]` advance, loop bottom.
- Bits absent (0x57680B): the erase — unlink the node (prev->_Next =
  next, next->_Prev = prev), `operator_delete` 0x7FC984, `dec [ebp+8]`
  (--size), esi = the unlinked node's next.
- Loop bottom (0x57682C): `UndoShare` 0x599E70([esi+8], ASYNCH,
  INFINITE) — NOTE: esi has already advanced in both sprite paths, so
  this releases the *next* node's id, a share this iteration never took,
  while the just-taken share is never released; only the non-sprite path
  (no advance) releases the right id. When the advance reached the
  sentinel the bottom still ran UndoShare with the head node's value
  slot before falling through. `cmp esi,[ebp+4]` the sentinel; jne loop.
- Tail (0x57685A): `ecx = this; push ebp; call 0x5765F0` — a direct
  call delegating to the parent strike with the filtered list;
  `ret 0x4`.

## Branch inventory

The GetShare check, the sprite gate, the warrior-mask test and the loop
control are all ported. The no-release failure exit, the non-sprite spin
and the off-by-one loop-bottom release are the original's behaviour, not
port artifacts — each carries a NOTE at the matching source line.

## Port

src/CProjectile.cpp, `// 0x5767A0`: a while loop over the list —
GetShare(*it), failure → return; non-sprite → no advance (the spin,
NOTE'd); sprite with `(GetAIType().m_nClassMask & (CLASSMASK_BARBARIAN |
CLASSMASK_FIGHTER | CLASSMASK_PALADIN | CLASSMASK_RANGER)) != 0` → ++it;
else `it = targets.erase(it)`. The loop bottom releases the id at the
*new* position (the exe's off-by-one, NOTE'd; ours skips the call at the
end position, where the exe passed the head node's value slot). After
the loop, `CProjectileArea8507C8::ApplyToTargets(targets)` — the exe's
direct 0x5765F0 call.

## Test

("the plain area effects decode straight to their ctors") — the override
