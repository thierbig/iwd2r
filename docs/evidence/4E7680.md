# 0x4E7680 CPtrList<CResRef*> deep-copy helper

File-local helper of CDerivedStats (DerivedStats.cpp), `__thiscall`
`CPtrList* CopyList(CPtrList* dst, const CPtrList* src)` (callee cleans 4
bytes), 148 bytes (0x4E7680-0x4E771B). Ported in this run as the file-local
`CopyResRefList` in src/CDerivedStats.cpp.

## Body

An empty source ([src+4] == 0, 0x4E769E-0x4E76A5) returns the destination
unchanged. Otherwise the loop walks the source's node chain: pNext read at
0x4E76AB, the node's data ([node+8], a CResRef*) at 0x4E76AD. Each
iteration allocates 8 bytes with operator new (0x4E76B0-0x4E76B2), runs the
CResRef default constructor on a non-null result (0x4E76C8-0x4E76CA,
0x78A960), copies the source value with CResRef::operator= (0x4E76E1,
0x78AC30 — the argument address is the source data pushed at 0x4E76D1), and
appends the copy with CPtrList::AddTail (0x4E76E9, 0x7FBE4E). The loop
repeats until pNext is null (0x4E76EE-0x4E76F0); the destination's prior
contents are not cleared. Returns the destination (eax = ebp).
