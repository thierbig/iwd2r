# 0x722D50 CGameSprite::ApplyClassAbilities

Member of CGameSprite in the original's GameSprite.cpp, `__thiscall`
`void ApplyClassAbilities(INT nClassType, INT nLevelsGained, BOOL
bFeedBack)`, 1548 bytes (0x722D50-0x723346). Named and declared in
src/CGameSprite.h (between sub_71E750 and sub_71E760) and ported in
commit 7b8e7e4ff.

## Body

Fetches the class-ability table via
`GetRuleTables().GetClassAbilityTable((BYTE) nClassType, GetSpecialization())`;
a NULL table returns immediately (which also skips the monk tail and the
attacks recompute). `nLevel` comes from `GetActiveStats()->GetClassLevel`.
A `nLevelsGained` of -1 grants every level row from 0; otherwise the walk
starts at `nLevel - nLevelsGained` and ends at `nLevel`. Each row walks
every column: `GetAt(CPoint(nRow, nColumn))` entries equal to the table's
default are skipped; the rest dispatch on the first three characters —
FA feeds back string reference 36 with the remaining number (the original
pushes whatever eax holds as the last two arguments, always 0 there since
the compare that dispatched returned 0), GA and RA add/remove the resref
as a special ability, AP expands the resref through
`IcewindMisc::GetSpellResrefEffects(this, resref, 1)`, stamps every
non-NULL effect's source resref, and `AddEffect`s it as
EFFECT_LIST_TIMED on TYPE_SPRITE objects; anything else asserts "Invalid
ability type". The original stores the AP resref at effect+0x90
(0x723012), which is m_sourceRes: CGameEffectBase declares it at +0x8C and
sits after CGameEffect's vptr, so the object offset is +0x90.

Per row, a class switch: barbarian levels 11, 14, 17, ... (>= 0xB and
(n-0xB) % 3 == 0) raise all eight elemental/physical resistance bases by
one; a cleric of the cleric-spec mask at level 1 gains BLIND_FIGHT plus
the base-stat delta pass sub_71E240; a monk gains DEFLECT_ARROWS at 2,
IMPROVED_EVASION at 9 (both with sub_71E240), +23 magic resistance at 13,
+1 per level past 13, and one field_3E every fifth level.

The tail: monks get `SetMonkAbilities()`; `GetAIType()` is called and the
result discarded; `sub_546B60(this, nBaseAttackBonus, nNumberOfAttacks,
nStep, FALSE)` recomputes the attack counts from three zeroed ints (the
original reads the second reference, [esp+0x20] after the ret 0x14, i.e.
the number of attacks, matching the in-tree callers' parameter naming),
clamps to 5, and stores `m_baseStats.m_numberOfAttacksBase`.

## Callers

In tree: sub_71E760's eleven per-class arms (src/CGameSprite.cpp, ported
in the same run) — the exe calls it from the same place, its only caller.

## Test

No dedicated test: the arms need the class-ability 2DAs, the special
ability lists and the spell-data stack around a live leveled sprite. The
wiring is exercised by tests/test_class_abilities.cpp, which drives
sub_71E760 on a live party sprite with every class level zeroed so the
eleven ApplyClassAbilities calls all take the level-zero skip path, and
asserts the observable drow/svirfneblin tail around them.
