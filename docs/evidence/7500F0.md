## Notes

Ported as CGameSprite::Rest in src/CGameSprite.cpp and wired as case 96 of
ExecuteAction (task 60). Rest in place: the MAGICAL_REST effect (292) goes
through DecodeEffect + CMessageAddEffect like every effect application, portrait
icon 0x27 comes off, and field_722A records the world timer's m_gameTime.

Spell refill walks the seven class lists by level: classes 0 and 5 (bard,
sorcerer) refill per level (delta field_14-field_18, sub_726150, then
CheckQuickLists for every entry of the level), the others per entry (delta
field_4-field_8, sub_726060 inside delta>0). The domain loop calls sub_726060
for every entry before the delta>0 test, keys CheckQuickLists with class 3
(CAIOBJECTTYPE_C_CLERIC) and field_1E = GetSpecializationIndex(cleric,
m_baseStats.m_specialization), resrefs from game->m_spells. The innate loop
calls sub_725C50(id, 0, TRUE) unconditionally, resrefs from
game->m_innateSpells, class key 0. Shapeshifts: sub_725D30(0, TRUE). Items:
every equipment slot but 10 with an ability flagged 0x800 gets its usage count
reset to maxUsageCount, CheckQuickLists keyed with itemType 2. When no session
is open or the sprite is the local player's, a CMessageSpriteUpdate goes out;
returns ACTION_DONE.

The original reads the effect's durationType from global 0x8491aa (holds 1);
Ghidra constant-folded it to `local_30 = 1`. uStack_8c/auStack_4c/auStack_44 are
Ghidra stack-slot reuse of the one ITEM_EFFECT and CAbilityId the asm builds.

No oracle case: the action needs a live game and a party character with spell
lists; covered by the Catch2 data test "sprite: Rest refills a memorized but
spent spell" (tests/test_sprite_actions.cpp, [ai][data], IWD2_DATA): a
memorized-twice, fully spent spell is castable again (field_8 == 2, and
field_18 == 2 on the bard/sorcerer per-level counts) after Rest returns
ACTION_DONE.
