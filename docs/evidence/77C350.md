# 0x77C350 CLUAConsole::CLUAConsole

The per-line construction of the console object, inlined into
CUIControlEditLua::OnEditReturn — the task's "inlined construction at
0x77C384": the empty-string store for the member at +0x4 (0x77C350, the
afxChNil copy from 0x8C1758), the CDWordArray ctor 0x7FB907 for the value
table at +0x10 (0x77C366), the CStringArray ctor 0x7FB98E for the token
store at +0x24 (0x77C377), the zero stores for +0x38/+0x3C (0x77C37C) and
+0x0/+0xC/+0x8 (0x77C384-0x77C38C). Ported as a real constructor in commit
702a30a68: the initializer list spells the five DWORD stores, the
class-type members default-construct, which is the exe's exact store
sequence. Declared in src/CLUAConsole.h next to the destructor 0x4EDA50,
whose listing already documented this construction's counterpart
destruction (0x77C3FC-0x77C42A, the reverse-order member dtors at scope
exit).

Before this port the class had no constructor, so stack locals (the tests,
and the handler before this task) built one with uninitialized DWORD
fields; the header comment's stale note that the Enter handler was "not
ported" went with it.
