# 0x45B290 sub_45B290

A free static in the original's GameAIBase.cpp neighborhood, `__cdecl`
`BOOL sub_45B290(const CString* psName, LPCTSTR szName)`, 28 bytes
(0x45B290-0x45B2AB). Ported with the TotalItemCnt trio arms that call it
(commit dba1e907), as a file-static in src/CGameAIBase.cpp.

## What it does

Answers TRUE when the two names differ. The body pushes both pointer
arguments straight into strcmp (0x7e7a54) -- there is no this-pointer
setup at either call site, which is what marks it free rather than a
member -- then normalizes the result with `neg eax; sbb eax,eax; neg
eax`: neg makes any nonzero 0/-nonzero, sbb fills eax with -1 exactly
when the value was nonzero, the final neg turns that -1 into 1. The
idiom is "x != 0", not "== 0"; an earlier working note read it as an
equality test and called the trio's fist branch dead, which the sensible
TotalItemCnt semantics (count everything carried but the inherent fist)
contradicts.

## Callers

resref ("00FIST", literal 0x8a7ff8), then against its seven-letter prefix
("00MFIST", literal 0x8a7ff0, through CString::Left 0x7FAA72).
