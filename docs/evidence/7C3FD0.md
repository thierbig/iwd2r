## Notes

The 32-bpp blob CParticle::Render's BLOB arm calls (0x7C37BB), the sibling of the new
RenderBlob16/RenderBlob24 (0x7C3CC0, 0x7C3E20). It draws five points, each PtInRect-clipped against
the clip rect moved to its own origin ({0, 0, right - left, bottom - top}) with the point moved in
by its top-left: up (y + 1, 0x7C4008), right (x + 1, 0x7C4030), left (x - 1, 0x7C4059), down
(y - 1, 0x7C407C) and the centre (x, y, 0x7C40A0), a DWORD at `pt.x + lPitch * pt.y`. Unlike the
16/24 helpers there is no nBlobSize switch: every call draws all five.

The port predated this task and drew only the four cross points; the first oracle run of
vid/particle_render caught it (one input in 2,700: the first whose centre fell inside the clip) and
the centre is added here from the disassembly above.
