# 0x452F50 CInfGameAreaLevel::CInfGameAreaLevel

The `CInfGameAreaLevel(const CString&)` overload, 48 bytes
(0x452F50-0x452F7F), `__thiscall` `ret 4`. Ported with the case 282
OverrideAreaDifficulty arm (0x44E042-0x44E12E) that constructs the record
when the area is not yet in `CInfGame::field_4BDC`.

## What it does

Copy-constructs `m_sArea` (+0, CString head) from the argument, then zeroes
the rest of the record in one breath: `m_dwFlags` (+4, dword), `m_nLevel`
(+8, byte) and `field_9` (+9, 15 bytes as 3 dwords + word + byte). The tree
spells the zeroing as two assignments and a `memset(field_9, 0, sizeof(...))`
with the same footprint.

The default construction is not a function in the original: every `new`
site inlines it (e.g. `CInfGame::Unmarshal` zeroes `m_dwFlags`, `m_nLevel`
and `field_9` right after the allocation), so the tree carries an
address-less `CInfGameAreaLevel()` next to this ctor for those sites.
