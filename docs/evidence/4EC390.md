# 0x4EC390 CtrlAltDelete_CreateCreature

The console's creature-spawn cheat (the JeffK pair below both funnel
here), free function consuming one CString by value (`ret 4`), 1,243
bytes (0x4EC390-0x4EC86A). Ghidra names it CtrlAltDelete_CreateCreature;
the name matches the body. Ported in commit (see report).

## Body

1. Constructs a CResRef from the argument and `CDimmKeyTable::FindKey`s
   it (0x78B410) with res type 1009 (creature, matching CCreatureFile's
   CResHelper<CResCRE, 1009>) on `cDimm.m_cKeyTable`. A miss prints
   "Error File " + name + " does not exist\n" through 0x4EC1C0 and
   returns.
2. Takes the visible area — `m_gameAreas[m_visibleArea]` off
   g_pBaldurChitin+0x1C54, spelled `GetObjectGame()->GetVisibleArea()`
   — and its CInfinity (area+0x4CC): `GetViewPosition` into locals, a
   CopyRect of rViewPort (CInfinity+0x48) into a local RECT, then
   `nGridX = (nViewX + (right-left)/2) / 16`,
   `nGridY = (nViewY + (bottom-top)/2) / 12`
   (GRID_SQUARE_SIZEX/SIZEY).
3. A `CCreatureFile` with the inlined `CResHelper::SetResRef` expansion
   (resref compare, `CDimm::GetResObject` 0x786DF0 for type 0x3F1,
   `CRes::Request`); the port spells it `SetResRef(CResRef(sName),
   TRUE, TRUE)` as CGameSpawning does.
4. `operator new` (0x7FC95B, 0x9D16 bytes) then — only if non-NULL —
   the CGameSprite ctor with (GetDataSize() first, then GetData(), 0,
   0, -1, 0, 0, 0x7FFFFFFF, CPoint(-1,-1), 0); on NULL the sprite
   pointer stays NULL. SetResRef(CResRef(GetResRefStr())) runs before
   the NULL check (CSpawn::ExecuteSpawn does the same), then
   `ReleaseData()`.
5. Inside `if (pSprite != NULL)`: a second SetResRef(CResRef(sName));
   a `CVariable` (0x452BD0); `CString` from the sprite's script name
   (sprite+0x554, char[32]), `CUtil::TrimLeft` (0x7FAF47), and only
   when the trimmed name is not the empty CString (strcmp against
   0x8C5CF8) `SetName(GetScriptName())`, `m_intValue = m_id`
   (sprite+0x5C → CVariable+0x28) and
   `m_namedCreatures.AddKey` (area+0xADA, vtable slot 0).
6. `CSearchBitmap::GetNearestOpenSquare` (0x548B80) from the center
   square with CGameObject::DEFAULT_TERRAIN_TABLE (0x84C524), the
   sprite's personal space (inlined GetPersonalSpace with the
   m_animation NULL assert 0x82D, file ObjAnimation.h — ours asserts
   inside CGameAnimation's accessor) and direction -1; then
   `CGameSprite::AddToArea` (vtable+8) with (area, CPoint(square.x*16,
   square.y*12), 0, GetListType()) — no GRID_SQUARE_SIZEX/2 term,
   unlike CSpawn::ExecuteSpawn's spawn point.

## ecx / calling convention

ecx is saved into esi at entry and forwarded only to the 0x4EC1C0
error-path call, which ignores it. Free function, `ret 4`.

## Callers

In-tree: CtrlAltDelete_JeffKAttacks (0x4EDF60) and
CtrlAltDelete_JeffKDefends (0x4EDF80). Not in tree: the console
dispatcher 0x5838A0 (deliberately unported; docs/followups.md).

## Test

None: every effect needs a loaded area with its search bitmap, a real
creature file and the engine's object array. Verified against the
listing above.
