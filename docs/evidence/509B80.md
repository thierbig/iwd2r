constructs a CMessage51, so the marshal arm below is dead in the game.

## Body

`__thiscall void Run()`, 187 bytes, `ret`. Deny the target (retry
SHARED/DENIED) and, when the object is a sprite (GetObjectType at vtable
+0x04 == 0x31), either call the virtual `SetTarget(const CPoint&, BOOL)` in
vtable slot +0xB8 with m_ptTarget and FALSE (point arm), or
`CGameSprite::SetTarget(CSearchRequest*, BOOL, BYTE)` at 0x707D40 with
m_pSearchRequest, FALSE and m_frontList (search arm, which transfers the
request's ownership to the sprite). The deny is released afterwards.
