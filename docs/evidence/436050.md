`{BYTE length; char resref[length]}` where `length = GetLength() & 0xFF` and the copy count is the
same low byte. Sent to every player: `SendSpecificMessage("", SEND_ALL_PLAYERS | SEND_GUARANTEED,
MSG_TYPE_MAPWORLD, MSG_SUBTYPE_MAPWORLD_REVEAL_AREA, payload, dwSize)`.

## Notes

1. The guard is the session only (not hosting, not the local player): `if
   (!g_pChitin->cNetwork.GetSessionOpen()) return FALSE;` (the ported accessor returns
   `m_bConnectionEstablished`).
2. The argument is a `CString` by value (`ret 4`); the header's existing FIXME about a reference
   stays.
3. The allocation/free is the file's `CreateBuffer`/`DestroyBuffer` (threshold 0x4000, static
   buffer 0x8D8FE4), matching the sibling senders.
4. `SendSpecificMessage` writes `{0xFF, type, subtype, payload}` into
   `CNetwork::STATIC_MESSAGE_BUFFER` before the dead DirectPlay path (`SendMessage_` returns
   FALSE); the sender ignores that result and returns TRUE. The unit test therefore sets a
   non-null service provider and compares the buffer.
5. Follow-up when the box returns: the Ghidra decompile draft (`tools/oracle.py evidence
   0x436050`) and the oracle case (static-buffer capture, report-T122 §4). The ASM structural
   parity waiver is not written here for the same reason.
