# 0x45B300 sub_45B300

A free static in the original's GameAIBase.cpp neighborhood,
`LONG sub_45B300(LONG x1, LONG y1, LONG x2, LONG y2)`, 31 bytes
(0x45B300-0x45B31E). Ported with the LOS arm that calls it (commit
0793bc4a), as a file-static in src/CGameAIBase.cpp.

## What it does

The squared distance between two grid points: the y difference
(0x45B30C) and the x difference (0x45B312), each squared by imul
(0x45B316/0x45B319) and summed (0x45B31C). Squared so the caller
compares it against a squared range, no square root anywhere.

## Callers

The CGameAIBase::EvaluateStatusTrigger (0x453840) LOS arm 0x4013, once
at 0x4546A6, on the two grid CPoints sub_45B2D0 produced; the arm reads
GetSpecifics twice, increments each read and squares the two increments
(0x4546BF/0x4546C5/0x4546C6) to build the squared range, then leaves
with the signed jg at 0x4546CB when the distance is strictly greater.
