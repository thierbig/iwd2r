`CUIControlPortraitWorld::OnLButtonUp` (0x77B160) calls it when one portrait is
released over another, then sorts the group. The body swaps the two ids of
`m_characterPortraits[6]` (+0x382E; `m_nCharacters` is +0x3846), refreshes each
character's portrait tooltip for the slot it moved into, and has the new leader

build the same message and the first only returns early. One deviation, not
