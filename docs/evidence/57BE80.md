## Notes

The skip condition's branch direction is the one subtlety: `jne
0x57c18a` on the `lower_bound`-result compare fires when the key IS in
the set (result != `_Myhead` == `find` != `end()`), and the following
`je` skips when the id equals `m_sourceId` — so the port's
`find(...) == end() && target != m_sourceId` is the exact negation. The
exe scales the direction with `shl eax,3` after a signed `movsx` from
the SHORT field, so negative directions index backwards through the
16-entry table exactly as `std::vector::operator[]` on the tree side
does with the sign-extended index.
