# 0x584420 CLUAConsole::CountArgs

The dispatcher's argument-count check: maps the resolved command id at
+0x0 to how many arguments (values at +0x8, tokens at +0xC) the command
expects, returning 0 when the console's counts do not match the command's
shape. 130 bytes (0x584420-0x5844A1); new method declaration on the
CLUAConsole class in src/CLUAConsole.h, body in src/CLUAConsole.cpp; ported
in commit (see report).

## Naming

Not named by any string; the body identifies it. It counts the console's
parsed arguments against the per-command expectation, so `CountArgs` after
its return value's role (the dispatcher 0x5838A0 consumes it to accept or
reject the line).

## Body

No SEH frame; `mov eax,[ecx]` reads field_0 directly. `add eax,-0xC` then
`cmp eax,0x1b / ja 0x584493` (0x584423-0x58442B): an id outside 12..39
(including the parse-state ids -1/-2/-3, which wrap unsigned) takes the
default arm. In range, the byte at 0x5844C4+eax (read at 0x58442F) selects
one of eight jump-table arms at 0x5844A4:

- arm 0 (0x58449E): returns 0.
- arm 1 (0x58443C): field_8 == 1 ? 1 : 0.
- arm 2 (0x58445A): field_C == 1 ? field_8 + 1 : 0.
- arm 3 (0x58444B): field_C == 2 ? 2 : 0.
- arm 4 (0x584468): field_C == 1 ? 1 : 0.
- arm 5 (0x584477): field_C == 2 && field_8 == 1 ? 3 : 0.
- arm 6 (0x58448C): returns field_8.
- arm 7 (0x584493): field_0 = -3, then `call 0x584320` (0x584499) with ecx
  unchanged (still the console) and return 0.

The tree spells the table as `bArgShape[28]` and the dispatch as a switch
on the arm number; the 28 table bytes are copied verbatim from 0x5844C4.
The id-to-arm mapping for the resolver's ids: FIRSTAID/HANS/MIDAS/EXPLOREAREA
/JEFFKATTACKS/JEFFKDEFENDS -> 0, ADDGOLD/ENABLECHEATKEYS/SETCURRENTXP -> 1,
ADDSPELL/CREATEITEM -> 2, CHECKVAR -> 3, MOVETOAREA -> 4, SETGLOBAL -> 5,
SETCHAPTER -> 6.

## ecx / calling convention

thiscall: ecx is the console (the dispatcher's this); reads this+0x0,
this+0x8, this+0xC, writes this+0x0 on arm 7. No arguments, plain `ret` at
0x5844A1 (caller-cleaned; esi is the only saved register).

## Callers

In the exe: the unported dispatcher 0x5838A0 (its wrong-count arm at
0x583DCB pairs the result with CommandNotFound) — no tree call site yet,
by design (the dispatcher stays unported, docs/followups.md). No TODO
references this address.

## Test

CountArgs cases in tests/test_cluaconsole.cpp [clua] drive the value arms
by setting field_0/field_8/field_C directly on a stack console:
SETGLOBAL (2,1) -> 3 and (2,2) -> 0, ADDGOLD (1,0) -> 1, CREATEITEM (1,3)
-> 4, FIRSTAID -> 0, CHECKVAR 2 strings -> 2, MOVETOAREA 1 string -> 1,
SETCHAPTER field_8=5 -> 5. Arm 7 prints (CommandNotFound -> live world
screen) and is pinned by the listing only.
