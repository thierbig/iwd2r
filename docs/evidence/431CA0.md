  `CItem::GetUsageCount(0/1/2)` (0x4E84B0), the word at item+0x1E (`m_wear`) and the dword at
  item+0x20 (`m_flags`) (0x431E19-0x431E6B). `errorCode` is the last dword in both shapes.
- Assert (0x431E86): `cnt == dwSize` (CBaldurMessage.cpp:6935).

## Notes

The port is the new `CBaldurMessage::SwapItemReply` in `src/CMessage.cpp`, called by the same PR's
`OnSwapItemRequest`. It keeps the request/reply protocol: the result byte, the optional item block
(resref + the three usage counts + wear + flags) and the trailing error code, sent as
SWAPITEM 73/114 to the requesting player with `SEND_GUARANTEED`.

Proof: the `OnSwapItemRequest` unit test's miss path exercises this helper end to end
(`{0, -1}` = 5 bytes) and reads the packet out of the static message buffer; the item block needs
a real CItem/game, hence the read-only kind.

**Follow-up (box off).** `python3 tools/oracle.py evidence 0x431CA0 --force` for the Ghidra
decompilation, and a real item fixture for the item-block shape. The name should also be checked
against the original's symbol list when the exports are refreshed.
