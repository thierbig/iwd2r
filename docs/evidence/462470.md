## Notes

- The resref comes from the action's override string (m_string1) when
  non-empty; otherwise DecodeSpell on m_specificID, and an empty decode is
  ACTION_ERROR before any spell object exists.
- m_curAction.m_internalFlags bit 0x20000000 overrides the caster level
  with m_specificID3's low byte; the default passed to GetAbilityEffect is
  0.
- Every effect built by GetAbilityEffect gets m_source = the caster
  position, m_sourceID = m_id and m_target = the target position before
  the fan-out looks at m_effect->m_targetType.
- Fan-out by target type: 1 queues a CMessageAddEffect to the caster with
  the effect's 0x2 flag set; 2 queues one to the target; 3 hands the
  effect to ApplyEffectToParty and deletes it; 4-8 hand it to
  CGameArea::ApplyEffectToSprites with the original's argument shapes
  (case 4 no flags, case 5 the first flag, cases 6 and 7 the second flag
  with the caster's or the target's AI-type specific value, case 8 passing
  the caster itself as the filter object) and delete it. Types 1 and 2
  give ownership to the message; types 3-8 delete the effect themselves --
  the same ownership split as ForceSpell. Any other target type trips the
  UTIL_ASSERT at CGameAIBaseActions.cpp line 2001.
