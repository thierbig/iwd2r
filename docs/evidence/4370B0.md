## Notes

1. The guard needs both the session and hosting (chitin+0x1032/+0x1033 =
   `cNetwork.m_bConnectionEstablished`/`m_bIsHost`): only the host broadcasts the clock.
2. The original sets `al` to 1/0 (a BOOLEAN return in its source); the imported header declares
   the function void, consistent with the adjacent senders (`WeatherBroadcast` is the same), so
   the port keeps void and leaves the result unused.
3. The allocation/free is the file's `CreateBuffer`/`DestroyBuffer`; the send's FALSE from the
   dead DirectPlay path is ignored.
4. Follow-up when the box returns: the Ghidra decompile draft and the oracle case (static-buffer
