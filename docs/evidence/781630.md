# 0x781630 CUtil::RotateFieldRight

## Body

Guarded returns first (0x781640-0x781668): `nValue == 0`, `nBits == 0`,
`nLowBits == 0` or `nLowBits >= nBits` (unsigned `jae`) return `nValue`
untouched. `nBits > 32` runs the UTIL_ASSERT "nBits <= 32" (ChUtil.cpp
line 1161, the sprintf/SuspendThreads/fatal-display block at
0x781673-0x7816C8); the tree spells it as the `UTIL_ASSERT` macro.

The field work (0x7816CD-0x781704): the top `nLowBits` bits of the
`nBits`-wide field wrap to the bottom —
`(nValue >> (nBits - nLowBits)) & ((1 << nLowBits) - 1)` — and the rest
shifts up — `nValue << nLowBits`. The shift-up is masked back to the
field width only when `nBits < 4` (0x7816F2 `cmp bl,4; jae`); at four or
more bits the shifted value is OR-ed in unmasked, so bits pushed past the
field's top survive in the result.
