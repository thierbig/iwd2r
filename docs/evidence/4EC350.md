# 0x4EC350 CtrlAltDelete_EnableCheatKeys

A debug console "CtrlAltDelete:" cheat-command handler, free function
consuming one INT by value (`ret 4`), 24 bytes (0x4EC350-0x4EC367).
Ported in commit (see report).

## Body

Five instructions, no calls: load g_pBaldurChitin (0x8CF6DC), load the
world screen from +0x1C88 (the port spells the inline load as the
`GetScreenWorld()` accessor), load the argument from [esp+4] and store
it into the screen at +0x156 — the flag CScreenWorld::OnKeyDown
consults for the Ctrl cheat keys, renamed `m_bCheatKeysEnabled` in the
tree (was `field_156`). The store in the port:

```cpp
g_pBaldurChitin->GetScreenWorld()->m_bCheatKeysEnabled = nEnable;
```

## ecx / calling convention

ecx is never read: the body starts at the globals. `ret 4` pops the
INT argument. Free function.

## Callers

Not in tree: the console dispatcher 0x5838A0 (deliberately unported;
docs/followups.md).

## Test

`tests/test_ctrl_alt_delete.cpp` swaps g_pBaldurChitin for a zeroed
buffer with a zeroed CScreenWorld behind m_pEngineWorld, calls the
handler with 1 and 0 and checks +0x156 follows — the store is the
whole function.
