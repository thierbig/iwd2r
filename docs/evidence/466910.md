# 0x466910 CGameAIBase::LeaveAreaLUAPanic

Member of CGameAIBase in the original's GameAIBase.cpp, `__thiscall`
`SHORT LeaveAreaLUAPanic()`, 240 bytes (0x466910-0x466A00). Ported with the
case 189 arm that calls it in fc5af5f7.

## Callers

One, ported in the same commit: the case 189 (LeaveAreaLUAPanic) arm of
CGameAIBase::ExecuteAction (0x44FF15-0x44FF1E), which loads the caller into
ecx, takes the return word into the dispatcher's return register, and jumps
to the shared done tail (0x4526F7) -- in tree, `returnValue =
LeaveAreaLUAPanic(); goto done;`.

## Notes

- The whole body is one gate: `mov edx,[0x8cf6d8]; cmp byte [edx+0x1032],1;
  jne 0x4669bb` reads g_pChitin->cNetwork.m_bConnectionEstablished and jumps
  past the hand-off when no session is established -- which is why the
  ported function answers ACTION_DONE in the single-player case.
- Before the gate the arguments are staged from m_curAction: ebp =
  [this+0x540] and ebx = [this+0x544] (m_dest x and y, CAIAction offset
  0x00CA), esi = [this+0x52C] (m_specificID, offset 0x00B6); the two string
  copies are built from GetString1()/GetString2(). The pushes before the
  call pass the dest point, the specific id, and the two string copies.
- The tail at 0x4669BB loads the return word from 0x8485C4 (ACTION_DONE,
  -1), destroys the two string copies, and returns it -- so both the
  connected and the disconnected path answer ACTION_DONE.
