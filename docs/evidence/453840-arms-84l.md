# 0x453840 CGameAIBase::EvaluateStatusTrigger, Task 84l arms

The dispatcher itself is 453840.md; this file records the last two arms
Task 84l ported, in commit e729e70f. Register roles as in the other arm
batches: edi = this, esi = bResult (0 from the arm's `xor esi, esi`),
ebx = 0 (the null-sprite compare), the decoded CAITrigger copy at
[esp+0x34], the acquired sprite out-param at [esp+0x10], the virtual's
return (bNoRelease) saved at [esp+0x28]. Both arms open with the shared
object prologue (push the sprite out-param at [esp+0x10], push the
trigger copy, `call [vtable+0xA4]` = GetTriggerSprite) and end with a
plain `jmp 0x45AD4C`, the common release tail reached by `break`.

## Callers

nothing else calls these ranges.

## Arm notes

- The 0x40E6 arm (0x455EDD) and the 0x40E7 arm (0x455F32) are back to
  back and byte-identical through the movsx skill load; only the final
  setcc differs (sete for 0x40E6, setg/setl for
  0x40E7/0x40E8). The port says so in a comment and keeps the three
  triggers in one case block, as the gold trio 0x404E-0x4050 already
  does, rather than inventing a helper the exe does not have.
- The rank compare is signed everywhere: the movsx of the signed-char
  rank and GetSpecifics' LONG meet in a plain `cmp`/setcc, so a rank of
  -3 equals specifics -3 (driven in the test).
- With these two arms ported, every jump-table arm of the dispatcher
  0x453840 is ported; the `default:` comment's sentence naming them as
  unported is dropped (the byte table 0x45B0C4 and jump table 0x45AE40
  facts were verified in 84k and stand).
