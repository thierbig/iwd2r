# 0x4ED2C0 CtrlAltDelete_Hans

A debug console "CtrlAltDelete:" cheat-command handler, free function
taking nothing (`ret`), 570 bytes (0x4ED2C0-0x4ED4F9). Named for the HANS
console word: the dispatcher's command-word resolver (0x583E60) maps the
word to id 0xD and dispatch arm 1 (the this+0x40 arm) calls here. Ported
in commit (see report).

## Body

Jumps the party to the mouse pointer.

1. Inlined GetObjectGame (global 0x8CF6DC + 0x1C54) gives the game; the
   visible area is `m_gameAreas[m_visibleArea]` (0x4ED2EE, 0x4ED2FD),
   spelled GetVisibleArea() in the port as in CreateCreature (0x4EC390),
   whose listing reads the same two members.
2. CInfinity::GetWorldCoordinates (0x5CDFC0) on the area's m_cInfinity
   (+0x4CC, 0x4ED309) converts the chitin's screen-space pointer position
   (g_pChitin 0x8CF6D8 + 0x1906, m_ptPointer, 0x4ED2F6) to world
   coordinates; returned through the hidden sret at [esp+0xC].
3. CAIAction(JUMPTOPOINT = 48 @ 0x8477D2, ptWorld, 0, -1): the listing
   inlines the 0x593D70 constructor — three CAIObjectType constructions
   (0x40AE80, all-zero enemy ally through alignment with nInstance = -1)
   at action+0x02/+0x3E/+0x7A, empty CString pointers from 0x8C1758 into
   m_string1/m_string2 (0x4ED36E), then the field stores m_actionID = 48
   (0x4ED401), m_specificID = 0 (0x4ED406), m_dest = ptWorld (0x4ED40D,
   0x4ED414), m_specificID2 = -1 (0x4ED41B), m_specificID3 = 0 (0x4ED426),
   m_internalFlags = 0 (0x4ED42D). The 0x403A40 default construction at
   0x4ED390 followed by five unwind dtors (0x4ED3A4-0x4ED3F4, members in
   reverse order of the temporary at [esp+0xEE]) is the constructor's
   dead construct-and-destroy quirk, present in the 0x593D70 listing
   itself; the port spells the out-of-line constructor and inherits it.
4. The game is re-fetched from the global (0x4ED45E), GetGroup (0x475DB0)
   gives the party group and CAIGroup::GroupAction (0x404D00) receives
   the action by value — push NULL (0x4ED434), push TRUE (0x4ED435),
   sub esp,0xD8 with the 0x409090 copy constructor filling the by-value
   slot (0x4ED459).
5. The action's own five unwind dtors run (0x4ED47F-0x4ED4DE) and the
   function returns `ret`.
