## Notes

- Two-phase cast keyed on field_753A: the first call plays the voice
  (all of string1, channel 2) and the casting loop (string2 before the
  ':', channel 4), decodes the effect picked by nID1 from the 26-entry
  table at 0x762488 (9-16 eight CASTINGGLOW flag sets, 17-34 nine
  SPARKLE amounts), arms the expiry `worldTime + max(0, nID2 -
  mentalSpeed) * 10 + 4` into field_753C, and holds the action. The
  tail polls the world timer and, at expiry, stops and re-arms
  field_4EC8 with string2 after the ':' (the release) and returns
  ACTION_DONE. field_753A set/clear guards re-entry.
- The three CMessagePlaySoundRef sends pass bForcePassThrough = FALSE;
  their GetCommType is BROADCAST_FORCED_OTHERS, so Broadcast deletes
  them unqueued in single player (ADR 0002) — the sounds are the direct
  CSound calls, the messages are the multiplayer echoes. The
  CMessageAddEffect queues normally.
- The caller arm must set bShare = TRUE (0x4516e7): GetTargetShareType
  resolved the actee with a share, so the release label must
  ReleaseShare it like sibling arms 16, 113/181 and 132. Without it the
  release path called ReleaseDeny on a shared object and the deny-count
  UTIL_ASSERT (CGameObjectArray.cpp:279) aborted the engine — found by
  the new test, fixed in c8c69fee.
