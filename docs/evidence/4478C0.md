# 0x4478C0 CDerivedStats::SumSorcererWizardLevels (Ghidra: CDerivedStats_SumSorcererWizardLevels)

The sorcerer/wizard level sum with a floor of 1. It is **not**
`CDerivedStats::GetSorcererWizardLevel` (0x4473B0, the neighbouring function):
that one returns 0 when neither class bit is set, while this one returns 1.
0x571A60 is its only caller and uses the result as the number of d4 to draw.

## Notes

`this` is a CDerivedStats: `[ebp+0x42]` is `m_classMask`, and the eleven
bytes at `[ebp+0x47 ... 0x51]` are `m_nClassLevels[0..10]` (the same union as
the named per-class bytes, with sorcerer at index 9 and wizard at 10).

- `edi = m_classMask & 0x600` (`CLASSMASK_SORCERER | CLASSMASK_WIZARD`).
- First pass: starts the bit at 1 (`eax`), walks it left until it exceeds
  0x600 (at most index 10), and for every bit present in `edi` adds the
  matching class-level byte into the 32-bit `esi`. The loop is bounded both
  by `eax > 0x600` and by `edx < 11`.
- If `edi` is 0, or the first sum is below 1, the function returns **1**.
- Otherwise it re-sums the same bits into a fresh accumulator (`eax`) and
  returns that (the original mirrors in the second pass what the first pass
  computed; ours computes the sum once and applies the same floor).
- The return is read one byte at a time (`movzx di, al` in 0x571A60), which
  the port's `BYTE` return type matches.

The port uses `CAIOBJECT_CLASS_MAX` (11) and the existing
`CLASSMASK_SORCERER`/`CLASSMASK_WIZARD` constants, and does not call
`GetClassMaskLevel` (0x447950): that helper has no floor, so it is the wrong
body for this address. Its sibling `GetSorcererWizardLevel` returns 0 for the
same input and stays untouched.

## Runtime coverage limits

The summation is pure, so `tests/test_visual_projectiles.cpp` exercises it
directly on a stack `CDerivedStats`: wizard-only (7), no class bits with
nonzero level bytes (1 against `GetSorcererWizardLevel()`'s 0), the class bit
with a zero level (1), and sorcerer+wizard (5). The caller's budget draw and
the source-type dispatch are covered by the same file's Circle of Death cases.
No oracle case runs the original function; this is read-only evidence plus
native tests.
