## Reconstruction notes

- `nProtectRange` starts as `SHORT(m_curAction.m_specificID / 16)` (the
  horizontal search-grid size); a zero result becomes 5000. A NULL protected
  object returns ACTION_ERROR. All other paths below return
  ACTION_INTERRUPTABLE.
- An empty selected weapon slot calls EquipMostDamagingMelee and immediately
  returns the interruptable result. Otherwise the item is demanded and the
  selected ability fetched. A missing ability, low-byte type 4, or an ability
  with usageFlags 3, zero current uses and nonzero maxUsageCount releases the
  weapon and returns interruptable (not error).
- Three default CAIObjectType locals are built at stack +0xB4, +0x78 and
  +0x3C, then filled by the first three Sets: +0xB4 and +0x78 both receive
  the protected object's m_lAttacker (0x74A138 and 0x74A142), and +0x3C
  receives this sprite's m_lAttacker (0x74A14F). +0xB4 is the selected-type
  holder that the branches below Set again to the attacker type they settle
  on; that value is otherwise unread, and the port keeps those Set calls.
  The stores at 0x74A130 and 0x74A134 execute while the first Set argument
  is pushed: adjusted for that push, they initialize the target-attacker
  object (base+0x34) and self-attacker object (base+0x18) to NULL, not the
  weapon at base+0x38.
- If the protected object's attacker is NOONE or NOT_SPRITE, only the
  protector's attacker is resolved. Otherwise the protected object's attacker
  is resolved first, then a usable self attacker. A missing target attacker
  falls back to the self attacker; a missing self attacker leaves the target
  attacker selected. If both exist: all three evil alignments choose self;
  all three neutral alignments choose self exactly when `rand() % 2 == 0`;
  every other alignment chooses the protected object's attacker.
- With an enemy, the byte-sized combined personal space is
  `((enemySpace - 1) >> 1) + ((selfSpace - 1) >> 1) - 1`. The near radius is
  `ability.range + nSpace + 1`; the far radius adds nProtectRange. Ranged
  abilities (low-byte type 2) use squared Euclidean grid distance; other
  attack types square CountSquares' grid distance. Above the far radius no
  action is taken; between far and near the sprite MoveToObject's the enemy;
  within near it drops an existing path, changes attackFrame -2 to -1 and
  calls Swing. Swing/MoveToObject results do not escape the handler.
- Without an enemy, distance to the protected object is CountSquares (not
  squared) and it walks there when that distance is greater than the signed
  SHORT minimum of nProtectRange and 6.
- The target-attacker share and self-attacker share are released in that order,
  then the weapon is released. The protected object's dispatcher-owned share is
  released outside the handler. The original's discarded protected-target and
  self GetPos calls at 0x74A4C9-0x74A4DF are kept.
