# 0x43E300 CBaldurProjector::sub_43E300 (subtitle machinery)

## What it is

The per-frame movie loop (`ret 4`, one stack arg `HBINK bnk`): BinkDoFrame,
CopyToBuffer into the DirectDraw back surface, Flip, NextFrame. This task
recovered the subtitle machinery the import-parked row names as its blocker
("goes on to render subtitle text; needs that subtitle rendering recovered
against the exe"): the per-frame advance (0x43E3F7-0x43E4D4, wired with
Render 0x43F9B0's port) and the per-frame composite tail (0x43E4DD-0x43E57C,
this commit). The vtable warning on this row (slot 0x0004 -> 0x43EA50, no
source decl) reproduces at base first.

## Decode (annotate 0x43E300-0x43E633)

- Prologue: `pSurface = pSurfaces[0]` (kept in ebp), `nType =
  m_pfnBinkDDSurfaceType(pSurface)`, guard `nDestX = (SCREENWIDTH -
  bnk->width)/2 >= 0 && nDestY = (SCREENHEIGHT - bnk->height)/2 >= 0`
  (0x43E38B/0x43E393, else bail to the epilogue at 0x43E629).
- 0x43E34A: `fontHeight = field_14A.GetFontHeight(1)` (global chain
  [0x8CF6DC]+0x1C5C+0x14A); `nBandY = SCREENHEIGHT - fontHeight*4` stored at
  [esp+0x2C] (0x43E3AB) - the subtitle band sits four font heights above the
  bottom.
- 0x43E3B5-0x43E3D0: `nDestXWide = (SCREENWIDTH - bnk->width * ((setne
  g_pBaldurChitin->field_4A28) + 1)) / 2` stored at [esp+0x10] - in
  widescreen mode the movie is drawn at twice its native width and the band
  follows the WIDENED position, while CopyToBuffer below keeps the
  native-width nDestX ([esp+0x18], pushed at 0x43E5E8).
- field_65A/EraseScreen block (0x43E3C6-0x43E3F1): pre-existing in the port.
- Advance 0x43E3F7-0x43E4D4: single NULL test on pProjectorSubtitles
  (0x43E3FE, je 0x43E583 skips advance AND composite); `field_4++` stored
  BEFORE the m_pLines NULL test (0x43E40C-0x43E412); `pLine =
  &m_pLines[field_C]` (one lea, 8-byte stride); `pLine->field_0 > 0 &&
  field_4 >= pLine->field_0` gates `m_sText = pLine->m_sText` (0x7FCD07),
  `field_C++`, the erase blt (DDBLTFX dwSize/dwFillColor at [esp+0xA4/+0xF4],
  CVidBlitter::Blt 0x43E4A6 with pSurfaces[8] dest, &rcRect as both rects,
  DDBLT_COLORFILL|DDBLT_WAIT, CheckResults 0x799F40, retry on
  DDERR_SURFACELOST/DDERR_WASSTILLDRAWING) and `Render()` (0x43E4D4).
- Composite 0x43E4DD-0x43E57C: runs EVERY frame under the same NULL test -
  BinkCopyToBuffer overwrites the back surface each frame, so the band must
  go on after the movie pixels. `nFontHeight = GetFontHeight(1)` (0x43E51F);
  `if (SCREENHEIGHT - nBandY <= nFontHeight*4) nBandY = SCREENHEIGHT -
  GetFontHeight(1)*4` (0x43E537 jg skips the recompute; with the prologue's
  own math the compare is equal, so the recompute at 0x43E54E is the path
  that runs - both calls ported). Then stdcall COM dispatch: pushes
  0x10 (DDBLTFAST_WAIT), &pProjectorSubtitles->rcRect, pSurfaces[8] (spilled
  at 0x43E51B), nBandY, nDestXWide (edi, taken at 0x43E4D9), pSurfaces[0],
  and `call [[pSurfaces[0]]+0x1C]` = IDirectDrawSurface::BltFast in the real
  ddraw layout: `pSurfaces[0]->BltFast(nDestXWide, nBandY, pSurfaces[8],
  &pProjectorSubtitles->rcRect, DDBLTFAST_WAIT)` - result ignored, no
  CheckResults. Ported as a normal C++ virtual BltFast on the shim's
  surface class (the 43F6D0 waiver's semantic-parity stance on COM
  dispatch).
- Tail (pre-existing in the port): BinkDoFrame (0x43E58B), Lock/Restore loop
  on DDERR_SURFACELOST, CopyToBuffer with nType|0xF0000000, Unlock, Flip,
  NextFrame iff frame_num != frames, `ret 4`.

## Port

`src/CBaldurProjector.cpp` `CBaldurProjector::sub_43E300`: the advance block
(wired with 0x43F9B0's port) is followed by the composite inside the same
`if (pProjectorSubtitles != NULL)`; nBandY/nDestXWide are computed before
the field_65A block as in the exe. `pSurface` (pSurfaces[0], the loop's own
local) is the BltFast destination.

## Tests

None added: the composite needs a live CVidMode with real DirectDraw
surfaces (BltFast through the shim's virtual) and a registered CVidFont -
the test harness has no video stack, and the whole loop sits behind
`m_hBinkDLL != NULL` (binkw32 LoadLibrary), unreachable in the sandbox.
