## Notes

The port is `CBaldurMessage::OnLeaveAreaLuaRequestToServer` in
`src/CMessage.cpp`, plus the new wire constant
`MSG_SUBTYPE_LEAVEAREALUA_PERMIT_REPLY = 114` (0x84CFD5). It keeps the two
entry guards, the payload layout, the remote-object Find, both settings counts
and feedback strings, the paused/save-mode/dialog/blocking/loaded-area answer
computation with the 4/3/0 codes, the 1-byte LEAVEAREALUA 88/114 reply, and the
`sub_5C3B20` transition call behind the code-1 gate.

The handler needed one callee fix: the already-ported
`CMultiplayerSettings::sub_518560` compared its `unsigned char` array against
`-1`, which is always true, so every slot was counted and the request was
always denied with the inventory feedback. It now compares against `0xFF`, as
the original's byte compare does (see docs/evidence/518560.md).

`sub_5C3B20` (4001 B, the actual area transition: area load, party move and the
LEAVEAREALUA 88/65 broadcast) is **not ported**; this branch declares it, adds
a no-op stub with `// TODO: 0x5C3B20` and calls it, so the permit handler's
decision and reply are complete and the transition becomes a drop-in later
(docs/evidence/5C3B20.md).

Proof: `tests/test_network.cpp`, `[msg][network]`, no `IWD2_DATA`:

- `... refuses without a session or a host` (the two entry guards);
- `... answers the permit request`: a zeroed `CBaldurChitin`/`CInfGame`/
  `CScreenWorld`, the remote array missing and the settings driven directly;
  checks the allow answer (reply `0xFF, 88, 114, 1` in
  `CNetwork::STATIC_MESSAGE_BUFFER`), the inventory feedback (0), the level-up
  feedback (0), the paused override (4), the save/load mode (0), the
  host-permitted dialog (0) and the blocking-message busy code (3).

The feedback `FeedBack` call, the loaded-area answer 3 and the transition need
a real sprite/area, hence the read-only kind.

**Follow-up.** The Ghidra decompile is now included above; port `CInfGame::sub_5C3B20`,
add a party/area fixture for the feedback and loaded-area arms, and the oracle case. Structural
parity flags the inlined CString/buffer helpers and the reply constant; the waiver records them.
