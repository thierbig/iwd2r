# 0x57B210 IcewindCProjectileScorcher::AIUpdate

Imported in batch i058.

## Decompiled

The port is anchored on the exe bytes (see exemption). The per-tick
update for the Scorcher flame wave:

1. Increments `m_tickCount` (32-bit wrap). Bails out early while a
   time stop is active and this projectile is not the caster's.
2. On `m_lifeSpan == 0`: removes itself from the area, asks the
   object array to delete the object (asynchronous), and
   `delete this` on SUCCESS.
3. Otherwise decrements the life span, advances the animation, and
   if a target is set shares it, mirrors its position into
   `m_targetPos` and its height delta into `m_deltaZ` (0 when the
   target left the area — the projectile removes itself then).
4. Denies the source object, points the source sprite at the
   target (`GetDirection`/`SetDirection`, or the projectile's own
   `GetDirection` for non-sprite sources), re-picks the direction
   sequence, releases the source, and re-reads the source position.
5. Every `m_clearPeriod` ticks clears the struck set; every
   `m_strikePeriod` ticks strikes the strike target once (guarded
   by the set) and gathers nearby targets.
6. Recomputes the segment chain: exact-scaled accumulators in
   `m_posExactX/Y` (Y pre-multiplied by 3/4), the 3/4-scaled
   distance, the segment count `ceil(distance / m_speed)` stored
   as a byte, and the exact-scaled per-segment steps in
   `m_deltaX/Y`.
7. Moves the looped sound to the projectile position.

// 0x57B210
void IcewindCProjectileScorcher::AIUpdate()
{
    m_tickCount = static_cast<LONG>(static_cast<DWORD>(m_tickCount) + 1);
    CInfGame* game = g_pBaldurChitin->GetObjectGame();
    if (game->m_nTimeStop != 0 && game->m_nTimeStopCaster != m_id) {
        return;
    }
    if (m_lifeSpan == 0) {
        RemoveFromArea();
        if (game->GetObjectArray()->Delete(m_id, CGameObjectArray::THREAD_ASYNCH, NULL, INFINITE)
            == CGameObjectArray::SUCCESS) {
            delete this;
        }
        return;
    }
    --m_lifeSpan;
    m_animation->FrameAdvance();
    if (m_targetId == CGameObjectArray::INVALID_INDEX) {
        m_deltaZ = 0;
    } else {
        CGameObject* target;
        BYTE rc = game->GetObjectArray()->GetShare(m_targetId, CGameObjectArray::THREAD_ASYNCH, &target, INFINITE);
        if (rc != CGameObjectArray::SUCCESS) {
            RemoveSelf();
            return;
        }
        if (m_pArea != target->m_pArea) {
            LONG targetId = m_targetId;
            RemoveSelf();
            game->GetObjectArray()->ReleaseShare(targetId, CGameObjectArray::THREAD_ASYNCH, INFINITE);
            return;
        }
        CPoint position = target->GetPos();
        m_targetPos.x = position.x;
        m_targetPos.y = position.y;
        m_deltaZ = static_cast<LONG>(static_cast<DWORD>(target->m_posZ) - static_cast<DWORD>(m_posZ));
        game->GetObjectArray()->ReleaseShare(m_targetId, CGameObjectArray::THREAD_ASYNCH, INFINITE);
    }
    CGameObject* source;
    BYTE rc;
    do {
        rc = game->GetObjectArray()->GetDeny(m_sourceId, CGameObjectArray::THREAD_ASYNCH, &source, INFINITE);
    } while (rc == CGameObjectArray::SHARED);
    if (rc != CGameObjectArray::SUCCESS) {
        return;
    }
    CPoint targetPoint(m_targetPos.x, m_targetPos.y);
    if (source->GetObjectType() == CGameObject::TYPE_SPRITE) {
        CGameSprite* sprite = static_cast<CGameSprite*>(source);
        m_nDirection = sprite->GetDirection(targetPoint);
        sprite->SetDirection(m_nDirection);
    } else {
        m_nDirection = GetDirection(targetPoint);
    }
    SetSequenceDirection(NULL);
    game->GetObjectArray()->ReleaseDeny(m_sourceId, CGameObjectArray::THREAD_ASYNCH, INFINITE);
    GetSourcePosition(m_sourceId, m_pos, TRUE);
    if (m_tickCount % m_clearPeriod == 1) {
        m_struckTargets.clear();
    }
    if (m_tickCount % m_strikePeriod == 1) {
        if (m_struckTargets.find(static_cast<DWORD>(m_strikeTarget)) == m_struckTargets.end()) {
            Strike(m_strikeTarget, TRUE);
            m_struckTargets.insert(static_cast<DWORD>(m_strikeTarget));
        }
        GatherTargets();
    }
    m_posExactX = static_cast<LONG>(static_cast<DWORD>(m_pos.x) << CGameSprite::EXACT_SCALE);
    m_posExactY = static_cast<LONG>((static_cast<DWORD>(m_pos.y) << CGameSprite::EXACT_SCALE) << 2) / 3;
    LONG targetY = static_cast<LONG>(static_cast<DWORD>(m_targetPos.y) << 2) / 3;
    LONG sourceY = static_cast<LONG>(static_cast<DWORD>(m_pos.y) << 2) / 3;
    LONG dy = static_cast<LONG>(static_cast<DWORD>(targetY) - static_cast<DWORD>(sourceY));
    LONG dx = static_cast<LONG>(static_cast<DWORD>(m_targetPos.x) - static_cast<DWORD>(m_pos.x));
    LONG distanceSquared = static_cast<LONG>(static_cast<DWORD>(dx) * static_cast<DWORD>(dx)
        + static_cast<DWORD>(dy) * static_cast<DWORD>(dy));
    LONG distance = static_cast<LONG>(static_cast<LONGLONG>(sqrt(static_cast<double>(distanceSquared)) + 0.5));
    if (distance == 0) {
        m_lifeSpan = 0;
        m_nSegments = 0;
    } else {
        LONG rounded = static_cast<LONG>(static_cast<DWORD>(m_speed) + static_cast<DWORD>(distance) - 1);
        m_nSegments = static_cast<BYTE>(rounded / m_speed);
        m_deltaX = static_cast<LONG>(static_cast<DWORD>(dx) << CGameSprite::EXACT_SCALE) / m_nSegments;
        m_deltaY = static_cast<LONG>(static_cast<DWORD>(dy) << CGameSprite::EXACT_SCALE) / m_nSegments;
    }
    m_sound.SetCoordinates(m_pos.x, m_pos.y, m_posZ);
}

## Notes

- The tick increment is a plain 32-bit `incl`, so `m_tickCount`
  wraps after 2^32 ticks; the port keeps the wrap with the
  DWORD cast instead of letting signed overflow be UB.
- The strike/clear gates test `== 1`, not `== 0`: the tick that
  trips a gate is the one after a multiple of the period.
- `m_deltaZ` is 0 while the projectile is untargeted and mirrors
  `target->m_posZ - m_posZ` otherwise; Render consumes its sign
  for the height drift along the segment chain.
- `SetSequenceDirection(NULL)` mirrors the exe pushing a NULL
  pVidCell argument at 0x57B4xx (the far register the fork's
  decompile loses is dead in the callee).
