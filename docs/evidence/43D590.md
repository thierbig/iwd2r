## Notes

1. Guards: the session, not hosting, and a non-empty host name.
2. The wait loop is the same `HandleBlockingMessages` + `m_bDisplayStale` + `SleepEx(60, FALSE)`
   loop as `DemandCharacterSlot` and the resource demand.
3. The exe compares `FindPlayerLocationByID(GetHostPlayerID(), FALSE)` with itself before storing
   the reply (0x43D729-0x43D791) — a redundant source-level expression; the port keeps the
   session re-check and stores the byte unconditionally after it (NOTEd in the code).
4. `SendSettingsNightmareMode` (0x43D3D0) and `OnSettingsNightmareMode` (0x43D520) were already
   ported on main; both were re-read against the disassembly with this port. `OnSettingsNightmareMode`
   compared `nMsgFrom` with `GetHostPlayerID()` (a location vs a PLAYER_ID); the exe compares the
   host's *location* (`FindPlayerLocationByID(GetHostPlayerID(), FALSE)`), which is the pattern
   the rest of the file uses — fixed here.
