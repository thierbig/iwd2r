# 0x4EC370 CtrlAltDelete_SetCurrentXP

A debug console "CtrlAltDelete:" cheat-command handler, free function
consuming one DWORD by value (`ret 4`), 25 bytes (0x4EC370-0x4EC388).
Ported in commit (see report).

## Body

Loads the argument from [esp+4], takes the world screen from
g_pBaldurChitin+0x1C88 (spelled `GetScreenWorld()` in the port), pushes
the argument and calls `CScreenWorld::SetCurrentXP` (0x6906F0); `ret 4`
then pops the handler's own argument. The port:

```cpp
g_pBaldurChitin->GetScreenWorld()->SetCurrentXP(dwCurrentXP);
```

## ecx / calling convention

ecx is never read. `ret 4` pops the DWORD argument; the callee
(0x6906F0) pops its own argument with its own `ret 4`. Free function.

## Callers

Not in tree: the console dispatcher 0x5838A0 (deliberately unported;
docs/followups.md).

## Test

None: the callee reaches the whole party's XP, which needs a loaded
game. Verified against the listing above.
