# 0x501420 CMessageInsertAction::UnmarshalMessage

Read-only evidence from the MD5-pinned original via
`python3 -I tools/parity/annotate.py 0x501420` and the Ghidra decompile
below; Ghidra names the function `FUN_00501420`.

## Class identity

The owning class is CMessageInsertAction, a 0xD8-byte CMessage subclass
whose only member is the CAIAction m_action at +0x0C (ctor 0x4F5830,
GetCommType 0x40A0D0 SEND, GetMsgType 0x40A0E0, GetMsgSubType 0x45BD10
subtype 27, Run 0x501730). It carries the same wire body as
CMessageAddAction (upstream #131): the CAIAction codec is shared, and the
port's test pins the two marshals byte for byte. The class is constructed
by the ported AI and effect code (CGameAIBase, CGameEffect), but the
marshal is only reached from the multiplayer Send branch
(docs/adr/0002-single-player-only.md).

## Body

`__thiscall BOOL UnmarshalMessage(BYTE* pData, DWORD dwSize)`, 775 bytes,
`ret 8`. Resolve the target pair (a miss returns FALSE, 0x5014F0). Read
m_actionID, then for each of the three object types: the length-prefixed
name, nine selector bytes, m_nClassMask, the instance pair (a hit stores
the local id, (0, 0xFFFFFFFF) stores INVALID_INDEX, any other miss returns
FALSE) and five SetSpecialCase bytes; copy the type into
m_action.m_actorID/m_acteeID/m_acteeID2 with CAIObjectType::Set. Then the
three specific ids, the two length-prefixed strings (SetString1/SetString2)
and m_dest, with the closing assert `cnt == dwSize`. The layout matches
CMessageAddAction's unmarshal (0x4F80B0), which decodes the same bytes.
## Wire format

Payload (without the 3-byte SPEC_MSG_HEADER): the target's remote pair
(PLAYER_ID m_remotePlayerID, LONG m_remoteObjectID; (0, 0xFFFFFFFF) when the
target does not resolve), SHORT m_actionID, then three CAIObjectType blocks
(each: SHORT name length and name, nine one-byte selectors, DWORD
m_nClassMask, the block's m_nInstance as a remote pair ((0, 0xFFFFFFFF)
when it does not resolve), five m_SpecialCase bytes), the three LONG
specific ids, the two length-prefixed strings and the destination CPoint.
The unmarshal resolves the target and every instance pair through
CGameRemoteObjectArray::Find and copies each decoded object into the action
with CAIObjectType::Set; an unresolved target or instance pair rejects the
message.
