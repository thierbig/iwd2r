# 0x5760B0 CProjectileArea8507C8::AIUpdate

Vtable slot 0x0C of the one-shot area strike (class documented in
docs/evidence/576080.md). The whole life of the carrier runs here, and it
is shorter than every sibling's: no Time Stop guard, no tick arithmetic,
no base chain — gather, apply, remove, done.

## Disassembly walkthrough (fresh, this task)

- SEH prologue (scope table 0x820478) and the sret slot
  (`lea ecx,[esp+0x8]`).
- `call [eax+0x90]` — `GetTargets()` (the 0x576310 override), result
  built into the sret slot.
- `push &sret; call [edx+0x94]` — `ApplyToTargets(targets)` (the
  0x5765F0 override).
- `call [edx+0x74]` — `RemoveSelf()`.
- The VC6-inlined `std::list<LONG>` destructor: unlink the head, one
  `operator_delete` 0x7FC984 per remaining node (loop at the tail), then
  delete the head node.

## Branch inventory

Every conditional in the body is the SEH state machinery or the inlined
list destructor's node loop — spelled constructs, not game logic. The
game-level port is a straight three-call sequence with the list's
destructor left to the compiler.

## Port

src/CProjectile.cpp, `// 0x5760B0` (VA-ordered right after the ctor):
`std::list<LONG> targets = GetTargets(); ApplyToTargets(targets);
RemoveSelf();`.
