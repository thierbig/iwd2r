The two guards are the session pair - `GetSessionOpen()` (chitin+0x1032) and
`GetSessionHosting()` (+0x1033, the host byte) - either false returns FALSE
with no side effects (0x434ED1-0x434EF4). Only the host announces the
chapter.

The payload (0x434EFA-0x434F73) is `{BYTE nChapter; BYTE length; the resref
chars}`, the resref from `CResRef::CopyToString` into a `CString` and then its
`GetBuffer`. The buffer is `CreateBuffer((length & 0xFF) + 2)` - the exe's
`cmp [0x8ABE0C], (len & 0xFF) + 2` against the static-buffer size, else
`operator_new`; a NULL buffer returns FALSE. The copy and the send use the
**full** length (`*(string - 8)`), not the low byte the size used; a resref is
at most 8 characters, so the two agree (kept literally, and noted in the
port).
