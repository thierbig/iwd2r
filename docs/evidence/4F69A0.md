## Notes

### Identity (survey row 63/110)

The vtable 0x84D30C slot 0x0C points at 0x4F69A0; the body loads the rdata
byte 0x84CF2B = 84 and returns it. Ghidra does not start a function here (the
address is only reachable through the vtable), so the parity marker column
stays yellow ("no function defined here") - the identity comes from the vtable
slot and the byte value, which the port's round-trip test also pins
(GetMsgSubType returns MSG_SUBTYPE_CMESSAGE_84).

The class and subtype constant are named from the survey's row (the original
class symbol is unknown). The accessor is exercised in-process by
tests/test_network.cpp.
