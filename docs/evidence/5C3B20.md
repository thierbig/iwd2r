# 0x5C3B20 CInfGame::sub_5C3B20

## Disassembly reading

`llvm-objdump` of the vanilla exe, 0x5C3B20-0x5C4ABE (4001 bytes,
`__thiscall`, `ret 0x18`), read only far enough to place the stub (the box is
off; there is no Ghidra decompile for this function yet). The exports call it
`FUN_005c3b20`.

- Prologue 0x5C3B35-0x5C3B3B: `sub esp, 0x5C`, saves `ecx` as `this`, loads
  `g_pBaldurChitin->m_pObjectGame`, asserts the game and the baldur message are
  non-null (0x5C3B42-0x5C3B7C).
- Six stack arguments (`ret 0x18`): `nCharacterId` [esp+0x7C], `x` [esp+0x80],
  `y` [esp+0x84], `direction` [esp+0x88], and two by-value `CString`s at
  [esp+0x8C] (area name) and [esp+0x90] (parchment). The role of the last two
  is fixed by the caller's copy order and by the call at 0x5C3CBB to
  `CBaldurMessage::sub_437D70` (the LEAVEAREALUA 88/65 broadcast, which takes
  the same two strings).
- On a host it calls `g_pBaldurChitin->GetBaldurMessage()->sub_437D70(...)`
  (0x5C3C60-0x5C3CD0, 88/65 at 0x84CFD3/0x84CFD7), then does the local party
  transition and the area load.

## Callers

- 0x4373E0 `CBaldurMessage::sub_4373E0` (0x437511, the host path of the
  `CGameSprite_LeaveAreaLUA` entry; a client sends 88/82 instead).
- 0x437950 `CBaldurMessage::OnLeaveAreaLuaRequestToServer` (0x437CBB, the
  permit handler's code-1 path).
- 0x437FD0 `FUN_00437fd0` (the other leave-area-Lua handler).

## Callees

A large set including 0x5C3770, 0x5B7510 `CInfGame::GetArea`, 0x5AD7E0,
0x5AF4E0, 0x518710/0x5186C0 (multiplayer settings), 0x599C70/0x59A010 (object
array), 0x7349A0 `CGameSprite::FeedBack`, 0x5872C0, 0x47A190, and the
`CString` helpers. Not mapped further.

## Notes

This task only declares `sub_5C3B20` in `src/CInfGame.h` and defines a no-op
stub in `src/CInfGame.cpp`:

```
// TODO: Incomplete. The 4,001-byte LeaveAreaLUA transition ...
```

`OnLeaveAreaLuaRequestToServer` calls it with
`(nCharacterId, x, y, direction, areaName, parchment)` exactly as the original
does, after answering 1 to the requester. The real port must load the
destination area, move the party (and familiars) to the panic point, set the
screen-world panic data and broadcast LEAVEAREALUA 88/65 to the clients.
