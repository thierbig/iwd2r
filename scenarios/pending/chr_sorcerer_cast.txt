# known list starts SPWI119, SPWI226, so rows 1-2 are permanently
# SPWI119 Larloch's Minor Drain (F1, missile 230) and SPWI226 Ray of
# Enfeeblement (F2, missile 232) -- both are the original's 0x57E370 /
# vtable 0x8511AC class, unported on ours (documented deviation: the
# default instant projectile). Task 78's remeasure over this recording
# decides which of the 28 not-exercised rows that class covers.
#
# NO spellbook step, unlike the druid: a sorcerer needs no memorization,
# and the CHR's castable counts (f18) are nonzero on every level
# (6/6/6/6/5/3), so the Task 59c rest problem (newly memorized spells
# read 0/1 until rest) does not apply -- every slot is castable as
# imported.
#
# Cast order: Ray of Enfeeblement FIRST (F2, row 2) -- it drains STR, no
# HP, so the 4 HP goblin stays alive as cast 2's target; its landing
# signal is the goblin's timed_effects going 0 -> 1 in enemy_creatures.
# Larloch's SECOND (F1, row 1) -- 1d4 per two levels, 5d4 at level 12,
# against 4 HP it is the kill; its landing signal is the goblin's hp
# drop or its absence from the list. No melee risk between the casts:
# run 20261030-141837 (ours) held the world unpaused beside the goblin
# for ~1000 frames with no enemy hp dropping -- a caster without an
# attack order does not retaliate.
#
# The walk and the fight are first_fight.txt's (solo party, seed 1),
# copied from chr_druid_cast.txt unchanged: the legs to the goblin, the
# Enemy Sighted auto-pause on leg 6, the goblin to 504,882 and its first
